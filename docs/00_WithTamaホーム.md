# WithTama 開発ホーム

Cursor と Obsidian の両方から参照する、WithTama 第1期開発のポータルです。  
**Vault = プロジェクトルート**（`docs/` 配下の Markdown を正本として Git 管理）。

---

## プロジェクト概要

WithTama は、命を大切に育てるブリーダーと、家族として迎えたい購入希望者をつなぐ Web サービスです。

第1期では以下を対象とします。

- 公開犬猫の閲覧（PU-01 / PU-02）
- ブリーダーのプロフィール・犬猫管理・問い合わせ対応
- 購入希望者のプロフィール・お気に入り・問い合わせ・見学希望
- 管理者による犬猫掲載審査（AD-10 / AD-11）
- 管理者によるブリーダー審査（AD-01 一覧実装済み / AD-02 設計確定）

**第1期スコープ外:** サイト内売買契約、犬猫代金のオンライン決済、Stripe、メール通知自動化、Realtime チャット等。

詳細: [[docs/02_要件定義/第1期要件定義]] / [[docs/00_プロジェクト全体設計/README]]
