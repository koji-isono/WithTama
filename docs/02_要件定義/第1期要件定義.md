# 第1期要件定義

## 目的

WithTama 第1期では、ブリーダーが犬猫を登録・管理し、購入希望者が情報を閲覧できる基盤を構築する。

## 対象ユーザー

| ロール | 説明 |
|--------|------|
| ブリーダー | 犬猫の登録・管理、ご縁（問い合わせ）対応 |
| 購入希望者（バイヤー） | 犬猫の検索・閲覧、問い合わせ |
| 管理者 | 審査・運用管理 |

## 第1期スコープ（概要）

### ブリーダー機能

- ダッシュボード（BR-06）
- 犬猫管理一覧（BR-07）— **実装済み（UI モック）**
- 犬猫新規登録（BR-08）
- 犬猫編集（BR-09）

### 公開機能

- トップページ
- 犬猫一覧・詳細
- ブリーダー詳細

### 認証・権限

- Supabase Auth による認証（次工程）
- ロールベースアクセス制御

## 非機能要件（概要）

- レスポンシブ対応（スマホ優先）
- TypeScript による型安全
- GitHub を設計書の正本とする
