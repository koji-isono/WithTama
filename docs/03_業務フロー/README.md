# 業務フロー

## 概要

WithTama における主要な業務フローを定義します。

## ブリーダー：犬猫登録〜掲載

```
ログイン
  → ダッシュボード（BR-06）
  → 犬猫管理一覧（BR-07）
  → 新規登録（BR-08）3ステップ
  → 写真アップロード（D&D）
  → 掲載申請 / 掲載
```

## 購入希望者：犬猫探索

```
トップページ
  → 犬猫一覧
  → 犬猫詳細
  → 問い合わせ（ご縁）
```

## 管理者：審査

```
管理画面
  → 掲載申請の確認
  → 承認 / 差し戻し
```
