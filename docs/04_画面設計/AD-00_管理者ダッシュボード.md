# AD-00 管理者ダッシュボード

| 項目    | 内容                                  |
| ------- | ------------------------------------- |
| 画面 ID | AD-00                                 |
| URL     | `/admin`                              |
| 種別    | 表示専用                              |
| 状態    | 部分実装（admin ガード + AD-10 導線） |

## 目的

管理者の入口画面。各運用機能への導線を提供する。

## 権限

- **admin のみ** アクセス可能（Decision No.102）
- `src/app/(admin)/admin/layout.tsx` で Server 側 `requireAdmin()` を実行
- 未ログイン → `/login` へ redirect
- buyer / breeder → 各入口（`/buyer` / `/breeder`）へ redirect

## 表示内容（現状）

- 画面 ID（AD-00）
- 「管理者ダッシュボード」
- 「管理者としてログインしています。」
- **運用メニュー** — 犬猫掲載審査（AD-10）への Card リンク → `/admin/pets/reviews`
- **今後追加予定** — ブリーダー審査 / 問い合わせ管理 / 会員管理（リンクなし）

## 今後追加予定
