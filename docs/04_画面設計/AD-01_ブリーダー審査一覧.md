# AD-01 ブリーダー審査一覧

| 項目    | 内容                      |
| ------- | ------------------------- |
| 画面 ID | AD-01                     |
| URL     | `/admin/breeders/reviews` |
| 種別    | 表示専用（一覧）          |
| 状態    | 実装済み（一覧）          |

## 目的

管理者がブリーダー申請（審査待ち系）を一覧で確認し、審査詳細（AD-02）へ遷移する。

## 権限

- **admin のみ** アクセス可能（Decision No.102）
- Server 側で `app_metadata.role = "admin"` を判定する（`requireAdmin()`）
- buyer / breeder は `/admin/breeders/*` にアクセス不可
- Service Role Key を通常画面処理で使用しない

## 一覧表示項目

| 項目           | データソース                            | 備考                                                           |
| -------------- | --------------------------------------- | -------------------------------------------------------------- |
| 屋号・事業所名 | `breeders.business_name`                | 空の場合は代表者名を表示                                       |
| 代表者名       | `breeders.representative_name`          |                                                                |
| 都道府県       | `breeders.prefecture`                   | 市区町村は一覧では省略可                                       |
| 審査状態       | `breeders.review_status`                | ラベル表示（submitted / under_review / resubmission_required） |
| 本人確認状態   | `breeders.identity_verification_status` | ラベルのみ                                                     |
| 登録証確認状態 | `breeders.business_verification_status` | ラベルのみ                                                     |
| 登録有効期限   | `breeders.registration_expires_at`      | 日付のみ。期限切れまたは 30 日以内は警告表示                   |
| 申請日時       | `breeder_review_logs.created_at`        | 最新の `action = submitted`（Decision No.131）                 |
| 詳細ボタン     | —                                       | AD-02 へ遷移                                                   |

### 一覧に表示しない項目（個人情報保護）

以下は **一覧に出さない**（AD-02 詳細でのみ表示）。

- `phone`
- `postal_code`, `address_line`
- `identity_document_path`, `business_license_path`
- 書類画像・Signed URL
- Stripe 関連（`stripe_*`, `subscription_status`）
- `user_id`

## 取得条件

- `breeders.review_status IN ('submitted', 'under_review', 'resubmission_required')`
- `breeders.deleted_at IS NULL`
- **ソート順:** 申請日時が古い順（`submitted_at ASC`）
  - 申請日時 = `breeder_review_logs` の `action = 'submitted'` の最新 `created_at`

第1期では `approved` / `rejected` の履歴一覧タブは **対象外**。

## 画面操作

| 操作       | 説明                                         |
| ---------- | -------------------------------------------- |
| 詳細を見る | `/admin/breeders/reviews/[breederId]` へ遷移 |

一覧から直接承認・差戻し・却下は行わない（AD-02 で実施）。

## 空状態

- 審査待ちのブリーダーが 0 件の場合、「審査待ちのブリーダー申請はありません」を表示
