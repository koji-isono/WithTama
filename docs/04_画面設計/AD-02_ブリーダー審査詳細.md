# AD-02 ブリーダー審査詳細

| 項目    | 内容                                      |
| ------- | ----------------------------------------- |
| 画面 ID | AD-02                                     |
| URL     | `/admin/breeders/reviews/[breederId]`     |
| 種別    | 表示 + 審査操作（審査開始実装済み / 承認・差戻し・却下は未実装） |

## 目的

管理者が個別のブリーダー申請を審査し、本人確認・登録証・プロフィールを確認したうえで、承認・差戻し・却下を行う。

Decision No.100 により、本人確認書類および登録証の原本確認は **本画面（AD-02）の責務** とする。AD-11（犬猫掲載審査）では書類画像を表示しない。

## 権限

- **admin のみ** アクセス可能（Decision No.102）
- Server 側で `requireAdmin()` を実行
- 審査操作は Server Action 経由 → 専用 RPC を呼び出す（Decision No.133）
- Service Role Key を通常画面処理で使用しない
- 画面表示だけでは `review_status` を自動変更しない（Decision No.126）

## 表示セクション

### 1. 基本情報

`breeders` から取得。

| 項目               | カラム                | 備考           |
| ------------------ | --------------------- | -------------- |
| 屋号・事業所名     | `business_name`       |                |
| 代表者名           | `representative_name` | admin のみ表示 |
| 電話番号           | `phone`               | admin のみ表示 |
| 公開用メール       | `public_email`        |                |
| Web サイト URL     | `website_url`         |                |

### 2. 所在地

| 項目     | カラム         | 備考           |
| -------- | -------------- | -------------- |
| 郵便番号 | `postal_code`  | admin のみ表示 |
| 都道府県 | `prefecture`   |                |
| 市区町村 | `city`         |                |
| 番地     | `address_line` | admin のみ表示 |

### 3. 第一種動物取扱業登録情報

| 項目       | カラム                         |
| ---------- | ------------------------------ |
| 登録種別   | `business_registration_type`   |
| 登録番号   | `business_registration_number` |
| 登録自治体 | `registration_authority`       |
| 有効期限   | `registration_expires_at`      |

有効期限が `CURRENT_DATE` より前、または NULL の場合は **警告表示** する。承認 RPC でも拒否する（Decision No.134）。

登録種別の適否については **システムは自動判定しない**。管轄自治体への確認が必要な事項として扱う。

### 4. プロフィール・方針

| 項目         | カラム                 |
| ------------ | ---------------------- |
| ブリーダー紹介 | `profile_text`       |
| 繁殖方針     | `breeding_policy`      |
| 健康管理方針 | `health_policy`        |
| 飼育環境     | `breeding_environment` |

Step3 入力内容と登録証画像の照合は **管理者の目視確認** とする。

### 5. 本人確認書類

| 項目     | カラム                     |
| -------- | -------------------------- |
| 確認状態 | `identity_verification_status` |
| 書類     | `identity_document_path`   |

- Server 側で `requireAdmin()` 確認後、admin セッション JWT で **短時間 Signed URL** を発行（Decision No.132）
- Storage RLS: `breeder_documents_storage_select_admin`（`breeder-documents` バケット・private のまま）
- 画像または PDF をプレビュー表示

利用可能書類の正式な範囲については **弁護士または運営責任者への確認が必要**。システムは書類種別の適否を自動判定しない。

### 6. 第一種動物取扱業登録証

| 項目     | カラム                    |
| -------- | ------------------------- |
| 確認状態 | `business_verification_status` |
| 書類     | `business_license_path`   |

- 本人確認書類と同様、Signed URL でプレビュー表示
- Step3 の登録情報と画像内容の整合を管理者が確認する

### 7. 審査状態

| 項目           | カラム                      | 備考                                      |
| -------------- | --------------------------- | ----------------------------------------- |
| 審査状態       | `review_status`             |                                           |
| 利用状態       | `membership_status`         | **参照のみ**。承認操作では変更しない（No.129 / No.130） |
| 承認日時       | `approved_at`               | 承認済みの場合のみ                        |
| Stripe 課金状態 | `subscription_status`      | 参照のみ（第1期 Stripe 未実装）           |

### 8. 審査履歴

`breeder_review_logs` を `created_at` 昇順で表示。

| 列       | 内容                                                              |
| -------- | ----------------------------------------------------------------- |
| 日時     | `created_at`                                                      |
| 操作     | `action`（submitted / review_started / approved / returned / rejected） |
| コメント | `comment`（差戻し・却下理由）                                     |
| 操作者   | `actor_user_id`（表示名は将来）                                   |

## 審査操作

| 操作       | 前提 `review_status`              | 遷移後                         | ログ `action`    | RPC                          |
| ---------- | --------------------------------- | ------------------------------ | ---------------- | ---------------------------- |
| 審査開始   | `submitted` または `resubmission_required` | `under_review`         | `review_started` | `start_breeder_review`       |
| 承認       | `under_review`                    | `approved`                     | `approved`       | `approve_breeder_review`     |
| 差戻し     | `under_review`                    | `resubmission_required`        | `returned`       | `return_breeder_review`      |
| 却下       | `under_review`                    | `rejected`                     | `rejected`       | `reject_breeder_review`      |

### 審査開始（Decision No.126）

- **`submitted` または `resubmission_required` のときのみ**「審査開始」ボタンを表示
- 管理者がボタンを押したときのみ `under_review` へ遷移する
- **画面表示だけでは `under_review` に変更しない**

### 承認（Decision No.129 / No.134）

サーバー側（RPC）で以下を **すべて** 再検証する。1 件でも満たさない場合は承認を拒否する。

| 条件               | 判定                                                         |
| ------------------ | ------------------------------------------------------------ |
| 審査状態           | `breeders.review_status = 'under_review'`                    |
| 本人確認書類       | `identity_document_path IS NOT NULL` かつ Storage 上に存在   |
| 登録証             | `business_license_path IS NOT NULL` かつ Storage 上に存在    |
| 登録有効期限       | `registration_expires_at IS NOT NULL`                        |
| 登録期限内         | `registration_expires_at >= CURRENT_DATE`                    |

承認時の DB 更新:

| カラム                         | 値              |
| ------------------------------ | --------------- |
| `review_status`                | `approved`      |
| `identity_verification_status` | `verified`      |
| `business_verification_status` | `verified`      |
| `approved_at`                  | `now()`         |
| `membership_status`            | **変更しない**（`pending` のまま） |

書類内容の法的適否は **システムで自動判定しない**。

### 差戻し（Decision No.127）

- 差戻し理由（`comment`）は **必須**
- `review_status` → `resubmission_required`
- `identity_verification_status` / `business_verification_status` は **原則 `submitted` を維持**（`unverified` へ自動戻ししない）
- ブリーダーは BR-09 で修正後、再提出できる（`resubmission_required` → `submitted`）

### 却下（Decision No.128）

- 却下理由（`comment`）は **必須**
- `review_status` → `rejected`
- **第1期では `rejected` からの再申請は不可**

### 操作ボタンの表示条件（第1期）

| `review_status`           | 審査開始 | 承認 | 差戻し | 却下 |
| ------------------------- | -------- | ---- | ------ | ---- |
| `submitted`               | ✅       | —    | —      | —    |
| `resubmission_required`   | ✅       | —    | —      | —    |
| `under_review`            | —        | ✅   | ✅     | ✅   |
| `approved` / `rejected`   | —        | —    | —      | —    |

## 公開・犬猫審査との関係

- 承認後も `membership_status = pending` のため、**一般公開条件（PU-01/02）は満たさない**（Decision No.130）
- 将来 Stripe 月額課金開始後に `membership_status = active` へ変更する
- AD-11 の犬猫公開承認（No.107）は `review_status = approved` かつ verification = `verified` 等を要求するが、`membership_status` は犬猫 RPC では検証しない（公開 View 側で `active` を要求）

## 未決定事項（第1期対象外）

| ------------------ | ------------------------ |
| 差戻し・却下通知メール | 第1期対象外              |
