# AD-10 犬猫掲載審査一覧

| 項目    | 内容                  |
| ------- | --------------------- |
| 画面 ID | AD-10                 |
| URL     | `/admin/pets/reviews` |
| 種別    | 表示専用（一覧）      |
| 状態    | 設計確定（未実装）    |

## 目的

管理者が `status = under_review` の犬猫掲載申請を一覧で確認し、審査詳細（AD-11）へ遷移する。

## 権限

- **admin のみ** アクセス可能（Decision No.102）
- Server 側で `app_metadata.role = "admin"` を判定する（Decision No.102 準拠）

## 一覧表示項目

| 項目         | データソース                                          | 備考                                                                                                                                                                               |
| ------------ | ----------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| メイン写真   | `pet_photos`（`is_main = true`）+ Signed URL          | admin SELECT のみ（Decision No.104）。RLS: `pet_photos_select_admin` / `pet_photos_storage_select_admin`（Migration: `20260810100000_add_admin_pet_photo_select_rls.sql`・未適用） |
| 公開表示名   | `pets.public_display_name`                            |                                                                                                                                                                                    |
| 品種         | `pets.breed`                                          |                                                                                                                                                                                    |
| ブリーダー名 | `breeders.business_name` または `representative_name` | `pets.breeder_id` で JOIN                                                                                                                                                          |
| 申請日時     | `pet_review_logs.created_at`                          | 最新の `action = submitted`（Decision No.98）                                                                                                                                      |
| 詳細ボタン   | —                                                     | AD-11 へ遷移                                                                                                                                                                       |

## 取得条件

- `pets.status = 'under_review'`
- `pets.deleted_at IS NULL`
- **ソート順:** 申請日時が古い順（`submitted_at ASC`）（Decision No.106）
  - 申請日時 = `pet_review_logs` の `action = 'submitted'` の最新 `created_at`（Decision No.98）

## 画面操作

| 操作       | 説明                                 |
| ---------- | ------------------------------------ |
| 詳細を見る | `/admin/pets/reviews/[petId]` へ遷移 |

一覧から直接承認・差戻しは行わない（AD-11 で実施）。

## 空状態

- 審査待ちの犬猫が 0 件の場合、「審査待ちの犬猫はありません」を表示
