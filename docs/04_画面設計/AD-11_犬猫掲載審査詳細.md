# AD-11 犬猫掲載審査詳細

| 項目 | 内容 |
|------|------|
| 画面 ID | AD-11 |
| URL | `/admin/pets/reviews/[petId]` |
| 種別 | 表示 + 審査操作 |
| 状態 | 設計確定（未実装） |

## 目的

管理者が個別の犬猫掲載申請を審査し、公開承認または差戻しを行う。

## 権限

- **admin のみ** アクセス可能（Decision No.102）
- Server 側で `app_metadata.role = "admin"` を判定する
- 審査操作は Server Action 経由。Service Role Key を通常画面処理で使用しない

## 表示セクション

### 1. 犬猫基本情報

`pets` から取得。

| 項目 | カラム |
|------|--------|
| 管理名 | `management_name`（管理者向け表示可） |
| 公開表示名 | `public_display_name` |
| 種別 | `species` |
| 品種 | `breed` |
| 性別 | `sex` |
| 誕生日 | `birthday` |
| 毛色 | `color` |
| 性格 | `temperament` |
| 紹介文 | `description` |
| 価格 | `price` |
| 価格補足 | `price_comment` |
| 掲載状態 | `status`（`under_review` であること） |

### 2. 写真一覧

- `pet_photos` から取得
- Server 側で admin 権限確認後、Signed URL を発行（Decision No.104）
- メイン写真を強調表示

### 3. ブリーダー情報

`breeders` から取得（`pets.breeder_id` で JOIN）。

| 項目 | カラム |
|------|--------|
| 屋号・事業所名 | `business_name` |
| 代表者名 | `representative_name` |
| 都道府県・市区町村 | `prefecture`, `city` |
| 公開用メール | `public_email` |
| ブリーダー紹介 | `profile_text` |

### 4. 方針情報

| 項目 | カラム |
|------|--------|
| 繁殖方針 | `breeding_policy` |
| 健康管理方針 | `health_policy` |
| 飼育環境 | `breeding_environment` |

### 5. 第一種動物取扱業登録情報

| 項目 | カラム |
|------|--------|
| 登録種別 | `business_registration_type` |
| 登録番号 | `business_registration_number` |
| 登録自治体 | `registration_authority` |
| 有効期限 | `registration_expires_at` |

**表示しないもの（Decision No.100）:**

- 本人確認書類画像（`identity_document_path`）
- 登録証画像（`business_license_path`）

原本確認はブリーダー審査側（将来の管理者ブリーダー審査画面）で扱う。

### 6. ブリーダー審査状態

| 項目 | カラム |
|------|--------|
| 審査状態 | `review_status` |
| 本人確認状態 | `identity_verification_status` |
| 登録証確認状態 | `business_verification_status` |

承認済みを表す `review_status` の実値は **未決定**。実 DB 定義確認後に実装する（Decision No.101）。

### 7. 審査履歴

`pet_review_logs` を `created_at` 昇順で表示。

| 列 | 内容 |
|----|------|
| 日時 | `created_at` |
| 操作 | `action`（submitted / returned / approved） |
| コメント | `comment`（差戻し理由等） |
| 操作者 | `actor_user_id`（表示名は将来） |

## 審査操作

| 操作 | 状態遷移 | ログ | 備考 |
|------|---------|------|------|
| 承認して公開 | `under_review` → `published` | `action = approved` | 前提条件をサーバー側で再検証（Decision No.101） |
| 差戻し | `under_review` → `draft` | `action = returned` | **差戻し理由入力必須**（Decision No.96） |

### 公開承認の前提条件（Decision No.101）

サーバー側で以下を再検証する。具体条件の実値は推測せず、実 DB 定義確認後に実装する。

- 当該ブリーダーが管理者審査で **承認済み** であること
- 公開に必要な第一種動物取扱業登録が **有効** であること

### 差戻し

- 差戻し理由（`comment`）は **必須**
- 差戻し後、ブリーダーは内容を修正し再度公開申請できる（`draft` → `under_review` → `pet_review_logs.action = submitted`）
