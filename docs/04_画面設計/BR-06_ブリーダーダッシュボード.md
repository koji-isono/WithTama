## 画面目的

ブリーダーがログイン後に最初に訪れる画面。登録犬猫数・ご縁件数・直近のアクティビティなどを一覧し、各機能への導線を提供する。

**本画面は表示専用とする。** プロフィール・犬猫・問い合わせ・設定の編集は、それぞれ独立 URL へ遷移して行う（Decision No.71, No.72）。

## 共通レイアウト

BR-06 はブリーダー共通レイアウト（DashboardLayout）内で表示する。

| デバイス | ナビゲーション                                   |
| -------- | ------------------------------------------------ |
| PC       | 左固定サイドバー（240px）                        |
| スマホ   | 下部固定ナビゲーション                           |
| 共通     | 上部ヘッダー（画面名・ブリーダー名・ログアウト） |

**第1期ヘッダー（Decision No.150）:**

| 要素         | 第1期                                                        |
| ------------ | ------------------------------------------------------------ |
| 画面名       | 表示                                                         |
| ブリーダー名 | Supabase 実データ（`business_name` / `representative_name`） |
| ログアウト   | Supabase Auth `signOut()` → `/login`                         |
| 通知ベル     | **非表示**（サイト内通知センターは将来対応）                 |

**第1期 PC サイドバー（Decision No.150）:** 実装済み route のみ（ダッシュボード / 犬猫管理 / 見学管理 / 問い合わせ / プロフィール / 月額会費）。`/breeder/settings` は **第1期非表示**。

## 想定コンテンツ

- サマリーカード（掲載中 12 / 審査中 2 / 家族決定 18 / お問い合わせ 5）
- 最近のお問い合わせ（ダミー 3件）
- 最近登録した犬猫（ダミー 2件）
- 「＋ 新しい犬猫を登録」ボタン

## 差戻し警告バナー（Decision No.135）

`review_status = resubmission_required` のとき、画面上部に警告バナーを表示する。

| 要素       | 内容                                                                       |
| ---------- | -------------------------------------------------------------------------- |
| 見出し     | 「申請内容に修正が必要です」                                               |
| 差戻し理由 | `breeder_review_logs` の最新 `action = returned` の `comment`              |
| 操作       | 「申請内容を修正する」→ `/breeder/profile/basic`（BR-09 プロフィール編集） |

- 専用「申請状況」画面は **第1期では作らない**
- 本画面は表示専用のまま。修正・再提出は BR-09 へ遷移して行う
