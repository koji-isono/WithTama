# BR-07 犬猫管理一覧

| 項目 | 内容 |
|------|------|
| 画面 ID | BR-07 |
| 画面名 | 犬猫管理一覧 |
| 画面 URL | `/breeder/pets` |
| 状態 | **実装済み** |
| 実装ファイル | `src/app/breeder/pets/page.tsx`, `src/app/breeder/pets/pet-management-list.tsx` |

## 画面目的

ブリーダーが登録した犬猫の一覧を確認・管理する画面。掲載状態の確認、検索・絞り込み、各犬猫への編集・写真・AI紹介文・ご縁画面への導線を提供する。

## 使用コンポーネント

| コンポーネント | 用途 |
|---------------|------|
| Button | 「新しい犬猫を登録」、掲載状態フィルター、カード内アクション |
| Input | 管理名・犬種・猫種の検索 |
| Card | 犬猫1件分のカード表示 |
| Badge | 掲載状態、写真枚数、ご縁件数 |

## 画面構成

```
┌─────────────────────────────────────────┐
│ BR-07  犬猫管理          [＋ 新しい犬猫を登録] │
├─────────────────────────────────────────┤
│ [🔍 管理名・犬種・猫種で検索            ] │
│ [すべて] [掲載中] [下書き] [非掲載]      │
├─────────────────────────────────────────┤
│ ┌──────┐ ┌──────┐ ┌──────┐             │
│ │ Card │ │ Card │ │ Card │  （3件表示）  │
│ └──────┘ └──────┘ └──────┘             │
└─────────────────────────────────────────┘
```

### カード内容

| 要素 | 内容 |
|------|------|
| 画像 | ダミー（グラデーション + アイコン） |
| 管理名 | 例: タマちゃん |
| 基本情報 | 犬種/猫種 · 性別 · 月齢（例: ラグドール · 女の子 · 3か月） |
| Badge（掲載状態） | 掲載中 / 下書き / 非掲載 |
| Badge（統計） | 写真12枚、ご縁5件 |
| ボタン | 編集 / 写真 / AI紹介文 / ご縁 |

## 画面イメージ

### レイアウト

- **スマホ:** 1列カード、ヘッダーは縦積み（タイトル → 登録ボタン全幅）
- **タブレット:** 2列グリッド
- **PC:** 3列グリッド、登録ボタンは右上

### デザイン

- WithTama ブランドカラー（`--primary: #a7654f`）をボタン・掲載中 Badge に使用
- カードは白背景 + 角丸 + 軽いシャドウ
- フィルターは pill 型 Button（アクティブ時 primary 色）

### ダミーデータ（3件）

| 管理名 | 犬種/猫種 | 性別 | 月齢 | 状態 | 写真 | ご縁 |
|--------|-----------|------|------|------|------|------|
| タマちゃん | ラグドール | 女の子 | 3か月 | 掲載中 | 12枚 | 5件 |
| モカちゃん | スコティッシュフォールド | 男の子 | 5か月 | 下書き | 6枚 | 0件 |
| ソラくん | ゴールデンレトリバー | 男の子 | 2か月 | 掲載中 | 18枚 | 9件 |

## 動作（現状）

- 検索: 管理名・犬種/猫種でクライアント側フィルター
- 掲載状態フィルター: すべて / 掲載中 / 下書き / 非掲載
- 該当なし時: 空状態メッセージを表示
- 各ボタン: UI のみ（遷移・API 未接続）
