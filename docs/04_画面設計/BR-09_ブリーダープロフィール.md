# BR-09 ブリーダープロフィール

| 項目 | 内容 |
|------|------|
| 画面 ID | BR-09 |
| 画面名 | ブリーダープロフィール |
| 入口 URL | `/breeder/profile`（リダイレクトのみ → `/breeder/profile/basic`） |
| 共通レイアウト | `src/app/breeder/profile/layout.tsx` |
| 状態 | Step 1 実装済み（DB 保存対応） |
| 実装ファイル | `src/app/breeder/profile/`、`src/features/breeder-profile/` |

## 画面目的

初回ログイン後、ブリーダーが掲載に必要なプロフィール情報を 5 ステップのウィザード形式で入力する（Decision No.64, No.67）。

## URL 構成（Decision No.67）

| Step | 内容 | URL | 状態 |
|------|------|-----|------|
| — | 入口 | `/breeder/profile` | リダイレクトのみ |
| 1 | 基本情報 | `/breeder/profile/basic` | **実装済み** |
| 2 | 所在地 | `/breeder/profile/location` | プレースホルダー |
| 3 | 第一種動物取扱業情報 | `/breeder/profile/license` | プレースホルダー |
| 4 | ブリーダー紹介 | `/breeder/profile/introduction` | プレースホルダー |
| 5 | 本人確認・登録証提出 | `/breeder/profile/verification` | プレースホルダー |

## 共通 UI（Decision No.68）

`profile/layout.tsx`（`ProfileWizardShell`）で以下を表示する。各 Step ページは入力フォームのみを持つ。

- 画面番号: BR-09
- タイトル: ブリーダープロフィール
- 説明: 掲載に必要な情報を順番に入力してください。
- Step 表示（例: Step 1 / 5 · 基本情報）
- プログレスバー（Step 番号から算出）

## Step 1: 基本情報（`/breeder/profile/basic`）

### 入力項目

| ラベル | DB カラム | 必須 | 備考 |
|--------|-----------|------|------|
| 屋号・事業所名 | `business_name` | 必須 | |
| 代表者氏名 | `representative_name` | 必須 | |
| 電話番号 | `phone` | 必須 | `inputMode="tel"` |
| 公開用メールアドレス | `public_email` | 任意 | 購入希望者へ公開する場合のみ |
| WebサイトURL | `website_url` | 任意 | |

### バリデーション（簡易）

- 必須 3 項目: 空欄不可
- `public_email`: 入力がある場合のみメール形式
- `website_url`: 入力がある場合のみ URL 形式（http / https）

### ボタン

| ボタン | 動作 |
|--------|------|
| 保存して次へ | バリデーション後、`saveBasicProfile` で DB 更新。成功時 `/breeder/profile/location` へ遷移 |
| あとで入力する | `/breeder/dashboard` へ遷移 |
