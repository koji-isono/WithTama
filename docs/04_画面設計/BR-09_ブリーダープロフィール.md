# BR-09 ブリーダープロフィール

| 項目           | 内容                                                              |
| -------------- | ----------------------------------------------------------------- |
| 画面 ID        | BR-09                                                             |
| 画面名         | ブリーダープロフィール                                            |
| 入口 URL       | `/breeder/profile`（リダイレクトのみ → `/breeder/profile/basic`） |
| 共通レイアウト | `src/app/breeder/profile/layout.tsx`                              |
| 状態           | Step 1〜5 実装済み（DB 保存・書類提出対応）                       |

## 画面目的

初回ログイン後、ブリーダーが掲載に必要なプロフィール情報を 5 ステップのウィザード形式で入力する（Decision No.64, No.67）。

## URL 構成（Decision No.67）

| Step | 内容                 | URL                             | 状態             |
| ---- | -------------------- | ------------------------------- | ---------------- |
| —    | 入口                 | `/breeder/profile`              | リダイレクトのみ |
| 1    | 基本情報             | `/breeder/profile/basic`        | **実装済み**     |
| 2    | 所在地               | `/breeder/profile/location`     | **実装済み**     |
| 3    | 第一種動物取扱業情報 | `/breeder/profile/license`      | **実装済み**     |
| 4    | ブリーダー紹介       | `/breeder/profile/introduction` | **実装済み**     |
| 5    | 本人確認・登録証提出 | `/breeder/profile/verification` | **実装済み**     |

## 共通 UI（Decision No.68）

`profile/layout.tsx`（`ProfileWizardShell`）で以下を表示する。各 Step ページは入力フォームのみを持つ。

- 画面番号: BR-09
- タイトル: ブリーダープロフィール
- 説明: 掲載に必要な情報を順番に入力してください。
- Step 表示（例: Step 1 / 5 · 基本情報）
- プログレスバー（Step 番号から算出）

## Step 1: 基本情報（`/breeder/profile/basic`）

### 入力項目

| ラベル               | DB カラム             | 必須 | 備考                         |
| -------------------- | --------------------- | ---- | ---------------------------- |
| 屋号・事業所名       | `business_name`       | 必須 |                              |
| 代表者氏名           | `representative_name` | 必須 |                              |
| 電話番号             | `phone`               | 必須 | `inputMode="tel"`            |
| 公開用メールアドレス | `public_email`        | 任意 | 購入希望者へ公開する場合のみ |
| WebサイトURL         | `website_url`         | 任意 |                              |

### バリデーション（簡易）

- 必須 3 項目: 空欄不可
- `public_email`: 入力がある場合のみメール形式
- `website_url`: 入力がある場合のみ URL 形式（http / https）

### ボタン

| ボタン         | 動作                                                                                       |
| -------------- | ------------------------------------------------------------------------------------------ |
| 保存して次へ   | バリデーション後、`saveBasicProfile` で DB 更新。成功時 `/breeder/profile/location` へ遷移 |
| あとで入力する | `/breeder/dashboard` へ遷移                                                                |

## Step 2: 所在地（`/breeder/profile/location`）

詳細: [BR-10 所在地](./BR-10_所在地.md)

## Step 3: 第一種動物取扱業情報（`/breeder/profile/license`）

### 入力項目

| ラベル     | DB カラム                      | 必須 | 備考                                       |
| ---------- | ------------------------------ | ---- | ------------------------------------------ |
| 登録種別   | `business_registration_type`   | 必須 | Select（7 種類）。管轄自治体への確認が必要 |
| 登録番号   | `business_registration_number` | 必須 | 前後空白を除去                             |
| 登録自治体 | `registration_authority`       | 必須 |                                            |
| 有効期限   | `registration_expires_at`      | 必須 | `type="date"`、本日以降                    |

### バリデーション

- 必須 4 項目: 空欄不可
- `registration_expires_at`: 本日以降
- 保存前に前後空白を除去

### 表示文言

- 「登録証に記載されている内容を正確に入力してください。」
- 「入力内容は、Step5で提出する登録証画像と管理者が照合します。」
- 「登録種別の適否については、管轄自治体へご確認ください。」

### ボタン

| ボタン       | 動作                                                                           |
| ------------ | ------------------------------------------------------------------------------ |
| 戻る         | `/breeder/profile/location` へ遷移                                             |
| 保存して次へ | `saveLicenseProfile` で DB 更新。成功時 `/breeder/profile/introduction` へ遷移 |

### 初期表示

`loadLicenseProfile` により、保存済みの breeders レコードをフォーム初期値として表示する。

## Step 4: ブリーダー紹介（`/breeder/profile/introduction`）

### 入力項目

| ラベル         | DB カラム              | 必須 | 備考                    |
| -------------- | ---------------------- | ---- | ----------------------- |
| ブリーダー紹介 | `profile_text`         | 必須 | Textarea、20〜1000 文字 |
| 繁殖方針       | `breeding_policy`      | 必須 | Textarea、20〜1000 文字 |
| 健康管理方針   | `health_policy`        | 必須 | Textarea、20〜1000 文字 |
| 飼育環境       | `breeding_environment` | 必須 | Textarea、20〜1000 文字 |

### バリデーション

- 4 項目すべて必須
- 保存前に前後空白を除去
- 各項目 20 文字以上、1000 文字以内

### 表示文言

- 「価格や見た目だけでなく、育った環境やブリーダーの想いが伝わるようにご記入ください。」
- 各 Textarea に現在文字数 / 1000 を表示

### ボタン

| ボタン       | 動作                                                                                |
| ------------ | ----------------------------------------------------------------------------------- |
| 戻る         | `/breeder/profile/license` へ遷移                                                   |
| 保存して次へ | `saveIntroductionProfile` で DB 更新。成功時 `/breeder/profile/verification` へ遷移 |

### 初期表示

`loadIntroductionProfile` により、保存済みの breeders レコードをフォーム初期値として表示する。

### AI 文章生成（将来方針）

- 第1期では本画面から AI 下書き生成は実装しない
- 将来 Dify で下書きを生成する予定
- AI 生成文を自動公開しない
- 公開フロー: AI 下書き → ブリーダー確認・修正 → 管理者審査 → 公開
- 健康状態・性格・血統・安全性を AI が事実確認なしに断定しない方針

## Step 5: 本人確認・登録証提出（`/breeder/profile/verification`）

### 入力項目

| ラベル                 | DB カラム                | 必須 | 備考                            |
| ---------------------- | ------------------------ | ---- | ------------------------------- |
| 本人確認書類           | `identity_document_path` | 必須 | 非公開 Storage パスのみ DB 保存 |
| 第一種動物取扱業登録証 | `business_license_path`  | 必須 | Step3 入力内容と管理者が照合    |

### Storage

| 項目     | 内容                                                |
| -------- | --------------------------------------------------- |
| バケット | `breeder-documents`（private）                      |
| パス例   | `breeders/{userId}/identity/{timestamp}-{uuid}.jpg` |
| 公開 URL | 発行しない                                          |

### ファイル制限

- 拡張子: jpg / jpeg / png / pdf
- MIME: `image/jpeg`, `image/png`, `application/pdf`
- 最大サイズ: 10MB / ファイル
- ファイル名は UUID + タイムスタンプへ変換して保存

### 提出完了時の DB 更新

| カラム                         | 値          |
| ------------------------------ | ----------- |
| `identity_verification_status` | `submitted` |
| `business_verification_status` | `submitted` |
| `review_status`                | `submitted` |
| `profile_completed`            | `true`      |

`membership_status` / `subscription_status` は変更しない。

### 必須項目チェック

Step1〜Step4 の必須項目および両書類パスが揃っている場合のみ `profile_completed = true` に更新する。不足ステップは画面に表示する。

### 表示文言

- 「提出書類は一般公開されません。運営会社による本人確認・登録内容確認にのみ使用します。」
- 本人確認書類: 利用可能書類の正式な範囲は弁護士または運営責任者への確認が必要
- 保存済みパスがある場合は「提出済み」（URL は表示しない）

### ボタン

| ボタン                     | 動作                                                             |
| -------------------------- | ---------------------------------------------------------------- |
| 戻る                       | `/breeder/profile/introduction` へ遷移                           |
| 提出してプロフィールを完了 | 両書類提出済みの場合のみ有効。成功時 `/breeder/dashboard` へ遷移 |

### 管理者確認フロー（AD-02）

- 管理者は [AD-02 ブリーダー審査詳細](../04_画面設計/AD-02_ブリーダー審査詳細.md) から Signed URL で書類を閲覧（Decision No.132）
- Step3 登録情報と登録証画像を照合
- 再提出は `review_status = resubmission_required` の場合のみ（Decision No.127）。`rejected` からの再申請は第1期不可（Decision No.128）
