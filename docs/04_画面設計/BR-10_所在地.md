## 画面目的

ブリーダーの事業所所在地を入力する（Decision No.80）。郵便番号検索 UI を前提としたフォーム構成とする（Decision No.79）。第1期では手入力と DB 保存のみ行い、郵便番号 API による自動補完は次工程とする。

## UI

| 項目 | 内容 |

| Progress | 40%（Step 2 / 5） |
| カードタイトル | 所在地 |

共通ヘッダー（BR-09・プログレスバー）は `profile/layout.tsx` で表示。

## 入力項目

| ラベル | DB カラム | 必須 | 備考 |
|--------|-----------|------|------|
| 郵便番号 | `postal_code` | 必須 | `NNN-NNNN` 形式、`inputMode="numeric"` |
| 都道府県 | `prefecture` | 必須 | Select（47 都道府県） |
| 市区町村 | `city` | 必須 | |
| 住所 | `address_line` | 必須 | 番地・建物名 |

## バリデーション

| 項目 | ルール |
|------|--------|
| 郵便番号 | 必須、`/^\d{3}-\d{4}$/` |
| 都道府県 | 必須、47 都道府県リストに含まれること |
| 市区町村 | 必須 |
| 住所 | 必須 |

## ボタン

| ボタン | 動作 |
|--------|------|
| 戻る | `/breeder/profile/basic` へ遷移 |
| 保存して次へ | `saveLocationProfile` で DB 更新。成功時 `/breeder/profile/license` へ遷移 |
