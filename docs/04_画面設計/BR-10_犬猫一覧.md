# BR-10 犬猫一覧

| 項目         | 内容                                                  |
| ------------ | ----------------------------------------------------- |
| 画面 ID      | BR-10                                                 |
| 画面名       | 犬猫一覧                                              |
| 画面 URL     | `/breeder/pets`                                       |
| 種別         | 表示（一覧）                                          |
| 状態         | **実装済み**                                          |
| 実装ファイル | `src/app/breeder/pets/page.tsx`, `src/features/pets/` |

## 画面目的

ブリーダーが登録した犬猫の情報・メイン写真・掲載状態を一覧で確認・管理する（Decision No.92）。

`draft` 状態の犬猫は公開申請（`draft` → `under_review`）が可能（Decision No.94, No.95）。

公開停止・掲載終了・管理者承認などは本画面では行わない。

## 取得条件

- `pets.breeder_id` = ログインユーザーの `breeders.id`
- `pets.deleted_at IS NULL`

他ブリーダーの犬猫は表示しない。

## 表示項目（Card）

| 項目       | 内容                                                                  |
| ---------- | --------------------------------------------------------------------- |
| メイン写真 | `pet_photos.is_main = true` の Signed URL。未登録時はプレースホルダー |
| 公開表示名 | `public_display_name`                                                 |
| 管理名     | `management_name`（「管理名：○○」）                                   |
| 犬猫種別   | `species`（犬 / 猫）                                                  |
| 品種       | `breed`                                                               |
| 性別       | `sex`（オス / メス）                                                  |
| 誕生日     | `birthday`（未入力：未登録）                                          |
| 価格       | `price`（3 桁区切り + 円、未入力：価格未設定）                        |
| status     | Badge（下書き / 審査中 / 公開中 / 一時停止 / 家族決定 / 掲載終了）    |
| 更新日時   | `updated_at`（例：更新：2026/08/06）                                  |

## レイアウト

- PC：2 列グリッド
- スマートフォン：1 列
- 右上（スマホでも押しやすい位置）：「犬猫を登録」Primary Button → `/breeder/pets/new`

## 操作

| ボタン     | 動作                                                                                      |
| ---------- | ----------------------------------------------------------------------------------------- |
| 犬猫を登録 | `/breeder/pets/new` へ遷移                                                                |
| 公開申請   | `status = draft` の Card のみ表示。確認後 `submitPetForReviewAction` で `under_review` へ |
| 編集       | `/breeder/pets/{petId}/edit` へ遷移                                                       |

## 公開申請

### 表示条件

- `status = draft` の Card のみ「公開申請」Primary Button を表示

### 確認ダイアログ

- 「この犬猫を公開申請しますか？」
- 「申請後は管理者による掲載内容の審査が行われます。」
- キャンセル / 公開申請する

### 申請条件（サーバー側）

1. ログイン済みブリーダー本人所有
2. `status = draft`
3. 犬猫登録と同じ必須項目が揃っている
4. 写真が 1 枚以上

### 成功時

- Badge が「下書き」→「審査中」
- 「公開申請を受け付けました。」

### 失敗時メッセージ例

- 写真なし：「公開申請には写真を1枚以上登録してください。」
- 状態不正：「この犬猫は現在、公開申請できません。」

## 空状態

- 「まだ犬猫が登録されていません。」
- 「最初の犬猫を登録しましょう。」
- 「犬猫を登録」ボタン

## エラー状態

一覧取得失敗時は Alert 表示。本番では内部エラー詳細を表示しない。

## 関連 API

- `loadBreederPets` — 一覧取得（`listPetsWithMainPhotoByBreederUserId`）
- `submitPetForReviewAction` — 公開申請（`draft` → `under_review`）
