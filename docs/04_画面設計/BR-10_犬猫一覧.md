# BR-10 犬猫一覧

| 項目         | 内容                                                  |
| ------------ | ----------------------------------------------------- |
| 画面 ID      | BR-10                                                 |
| 画面名       | 犬猫一覧                                              |
| 画面 URL     | `/breeder/pets`                                       |
| 種別         | 表示（一覧）                                          |
| 状態         | **実装済み**                                          |
| 実装ファイル | `src/app/breeder/pets/page.tsx`, `src/features/pets/` |

## 画面目的

ブリーダーが登録した犬猫の情報・メイン写真・掲載状態を一覧で確認・管理する（Decision No.92）。

`draft` 状態の犬猫は公開申請（`draft` → `under_review`）が可能（Decision No.94, No.95）。

`published` 状態の犬猫は公開停止（`published` → `paused`）が可能（Decision No.152）。

`paused` 状態の犬猫は再公開（`paused` → `published`）が可能。再審査は不要（Decision No.152）。

掲載終了（`family_decided` / `closed`）・管理者承認は本画面では行わない。

## 取得条件

- `pets.breeder_id` = ログインユーザーの `breeders.id`
- `pets.deleted_at IS NULL`

他ブリーダーの犬猫は表示しない。

## 表示項目（Card）

| 項目       | 内容                                                                                       |
| ---------- | ------------------------------------------------------------------------------------------ |
| メイン写真 | `pet_photos.is_main = true` の Signed URL。未登録時はプレースホルダー                      |
| 公開表示名 | `public_display_name`                                                                      |
| 管理名     | `management_name`（「管理名：○○」）                                                        |
| 犬猫種別   | `species`（犬 / 猫）                                                                       |
| 品種       | `breed`                                                                                    |
| 性別       | `sex`（オス / メス）                                                                       |
| 誕生日     | `birthday`（未入力：未登録）                                                               |
| 価格       | `price`（`formatPetPrice` — 未入力：価格未設定、入力時：`…円（税抜）`）（Decision No.153） |
| status     | Badge（下書き / 審査中 / 公開中 / 一時停止 / 家族決定 / 掲載終了）                         |
| 更新日時   | `updated_at`（例：更新：2026/08/06）                                                       |

## レイアウト

- PC：2 列グリッド
- スマートフォン：1 列
- 右上（スマホでも押しやすい位置）：「犬猫を登録」Primary Button → `/breeder/pets/new`

## 操作

| ボタン     | 動作                                                                                      |
| ---------- | ----------------------------------------------------------------------------------------- |
| 犬猫を登録 | `/breeder/pets/new` へ遷移                                                                |
| 公開申請   | `status = draft` の Card のみ表示。確認後 `submitPetForReviewAction` で `under_review` へ |
| 公開を停止 | `status = published` の Card のみ表示。確認後 `pausePetListingAction` で `paused` へ      |
| 再公開する | `status = paused` の Card のみ表示。確認後 `resumePetListingAction` で `published` へ     |
| 編集       | `/breeder/pets/{petId}/edit` へ遷移                                                       |

## 公開申請

### 表示条件

- `status = draft` の Card のみ「公開申請」Primary Button を表示

### 確認ダイアログ

- 「この犬猫を公開申請しますか？」
- 「申請後は管理者による掲載内容の審査が行われます。」
- キャンセル / 公開申請する

### 申請条件（サーバー側）

1. ログイン済みブリーダー本人所有
2. `status = draft`
3. 犬猫登録と同じ必須項目が揃っている
4. 写真が 1 枚以上

### 成功時

- Badge が「下書き」→「審査中」
- 「公開申請を受け付けました。」

### 失敗時メッセージ例

- 写真なし：「公開申請には写真を1枚以上登録してください。」
- 状態不正：「この犬猫は現在、公開申請できません。」

## 公開停止（Decision No.152）

### 表示条件

- `status = published` の Card のみ「公開を停止」Button を表示

### 確認ダイアログ

- 「公開停止の確認」
- 「この犬猫の公開を停止しますか？」
- 停止の影響説明（公開一覧・詳細から非表示、問い合わせ・見学履歴は保持）
- 紹介文変更審査中（`description_review_status = under_review`）は追加で変更案取消の説明
- キャンセル / 公開を停止

### 成功時

- Badge が「公開中」→「一時停止」
- 「公開を停止しました。」

## 再公開（Decision No.152）

### 表示条件

- `status = paused` の Card のみ「再公開する」Button を表示

### 確認ダイアログ

- 「再公開の確認」
- 「停止前に承認されていた内容で再び公開されます。」
- キャンセル / 再公開する

### 成功時

- Badge が「一時停止」→「公開中」
- 「再公開しました。」
- 管理者による掲載再審査は不要

## 空状態

- 「まだ犬猫が登録されていません。」
- 「最初の犬猫を登録しましょう。」
- 「犬猫を登録」ボタン

## エラー状態

一覧取得失敗時は Alert 表示。本番では内部エラー詳細を表示しない。

## 関連 API

- `loadBreederPets` — 一覧取得（`listPetsWithMainPhotoByBreederUserId`）
- `submitPetForReviewAction` — 公開申請（`draft` → `under_review`）
- `pausePetListingAction` — 公開停止（`published` → `paused`）
- `resumePetListingAction` — 再公開（`paused` → `published`）
