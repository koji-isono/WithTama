# BR-10 犬猫登録

| 項目 | 内容 |
|------|------|
| 画面 ID | BR-10 |
| 画面名 | 犬猫登録 |
| 画面 URL | `/breeder/pets/new` |
| 種別 | 編集（新規登録） |
| 状態 | **実装済み**（基本情報・下書き保存） |
| 実装ファイル | `src/app/breeder/pets/new/page.tsx`, `src/features/pets/` |

## 画面目的

ブリーダーが犬猫の基本情報を入力し、`public.pets` へ下書き（`status = draft`）として登録する。

## 入力項目

| ラベル | DB カラム | 必須 | 備考 |
|--------|-----------|------|------|
| 管理名 | `management_name` | 必須 | ブリーダー内部用。購入希望者には非表示 |
| 公開表示名 | `public_display_name` | 必須 | |
| 犬猫種別 | `species` | 必須 | `dog` / `cat`（犬 / 猫） |
| 犬種・猫種 | `breed` | 必須 | 第1期は自由入力 |
| 性別 | `sex` | 必須 | `male` / `female`（オス / メス） |
| 誕生日 | `birthday` | 任意 | 未来日不可 |
| 毛色 | `color` | 任意 | |
| 性格 | `temperament` | 任意 | 500 文字以内 |
| 価格 | `price` | 任意 | 0 以上の整数（円） |
| 価格補足 | `price_comment` | 任意 | 500 文字以内 |

## 登録時の DB 初期値

| カラム | 値 |
|--------|-----|
| `status` | `draft`（固定。クライアントから変更不可） |
| `display_order` | `0` |
| `published_at` | `null` |
| `deleted_at` | `null` |
| `created_by` | `auth.users.id` |
| `updated_by` | `auth.users.id` |
| `breeder_id` | サーバー側で `breeders.id` を解決（Decision No.84） |

## バリデーション

- 必須 5 項目: 空欄不可
- 保存前に前後空白を除去
- `birthday`: 本日以前
- `temperament` / `price_comment`: 500 文字以内
- `price`: 未入力または 0 以上の整数

## ボタン

| ボタン | 動作 |
|--------|------|
| 一覧へ戻る | `/breeder/pets` へ遷移 |
| 下書き保存 | `createPetDraft` で INSERT。成功時 `/breeder/pets/{petId}/edit` へ遷移 |
