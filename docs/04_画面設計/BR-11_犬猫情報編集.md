# BR-11 犬猫情報編集

| 項目         | 内容                                                               |
| ------------ | ------------------------------------------------------------------ |
| 画面 ID      | BR-11                                                              |
| 画面名       | 犬猫情報編集                                                       |
| 画面 URL     | `/breeder/pets/[petId]/edit`                                       |
| 種別         | 編集（Decision No.72）                                             |
| 状態         | **実装済み**（基本情報編集・写真管理）                             |
| 実装ファイル | `src/app/breeder/pets/[petId]/edit/page.tsx`, `src/features/pets/` |

## 画面目的

ブリーダー本人が、自分の犬猫の基本情報と写真を表示・編集する。他ブリーダーの犬猫は参照・更新できない（Decision No.85）。

掲載ステータス（`status`）の変更は本画面では行わない（Decision No.86）。

## 取得条件

- `pets.id = petId`
- `pets.deleted_at IS NULL`
- `pets.breeder_id` = ログインユーザーの `breeders.id`

該当なしの場合は `notFound()`。

## 編集項目（基本情報）

BR-10 犬猫登録と同じ項目。

| ラベル     | DB カラム             | 必須 |
| ---------- | --------------------- | ---- |
| 管理名     | `management_name`     | 必須 |
| 公開表示名 | `public_display_name` | 必須 |
| 犬猫種別   | `species`             | 必須 |
| 犬種・猫種 | `breed`               | 必須 |
| 性別       | `sex`                 | 必須 |
| 誕生日     | `birthday`            | 任意 |
| 毛色       | `color`               | 任意 |
| 性格       | `temperament`         | 任意 |
| 価格       | `price`               | 任意 | **税抜**（Decision No.141） |
| 価格補足   | `price_comment`       | 任意 |

### 編集対象外（表示のみ）

- `status` — Badge 表示。フォームから変更不可

## 写真セクション

基本情報カードの下に「写真」カードを表示する。

| 項目     | 内容                                                   |
| -------- | ------------------------------------------------------ |
| タイトル | 写真                                                   |
| 説明     | 犬猫の様子や育った環境が伝わる写真を登録してください。 |
| 枚数表示 | 例: 3 / 10 枚                                          |
| 許可形式 | jpg / jpeg / png（各 10MB 以内）                       |
| 上限     | 1 匹あたり最大 10 枚（Decision No.88）                 |
| 表示     | Signed URL（非公開 Storage、Decision No.87）           |
| 並び替え | 第1期は未実装（Decision No.89）                        |

### 写真一覧の各項目

- サムネイル（Signed URL）
- メイン写真 Badge（`is_main = true` の場合）
- 「メイン写真にする」ボタン（メイン以外）
- 「削除」ボタン
- アップロード日時（`created_at`）

表示順: `display_order` 昇順 → `created_at` 昇順。

### 写真操作

| 操作           | Server Action           |
| -------------- | ----------------------- |
| アップロード   | `uploadPetPhotoAction`  |
| メイン写真設定 | `setMainPetPhotoAction` |
| 削除           | `deletePetPhotoAction`  |

Storage パス: `breeders/{authUserId}/pets/{petId}/{uuid}.{ext}`（バケット `pet-photos`、private）。

## ステータス Badge

| status           | 表示     |
| ---------------- | -------- |
| `draft`          | 下書き   |
| `under_review`   | 審査中   |
| `published`      | 公開中   |
| `paused`         | 一時停止 |
| `family_decided` | 家族決定 |
| `closed`         | 掲載終了 |

## ボタン

| ボタン       | 動作                                                                         |
| ------------ | ---------------------------------------------------------------------------- |
| 一覧へ戻る   | `/breeder/pets` へ遷移                                                       |
| 変更を保存   | `updatePetDraftAction` で UPDATE。成功時同画面に留まり「保存しました」を表示 |
| アップロード | `uploadPetPhotoAction`。成功時同画面に留まり Alert 表示                      |

## 関連 API

- `getPetEditData` / `loadPetEditPageData` — 初期表示（基本情報 + 写真 Signed URL）
- `updatePetDraftAction` — 基本情報更新
- `uploadPetPhotoAction` — 写真アップロード
- `setMainPetPhotoAction` — メイン写真設定
- `deletePetPhotoAction` — 写真削除
