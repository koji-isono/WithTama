## 画面目的

承認済みブリーダーが **月額会費（Stripe Subscription）** の支払い開始、状態確認、Customer Portal 経由のカード変更・解約を行う。

## 表示要素

| 要素            | 内容                                                                                   |
| --------------- | -------------------------------------------------------------------------------------- |
| 会員状態        | `membership_status` ラベル                                                             |
| 審査状態        | `review_status != approved` の場合は課金不可メッセージ                                 |
| 月額料金        | Stripe Price retrieve — **税抜額** + **税込総額（表示用）**。固定「5,000円」文字列禁止 |
| 支払い開始      | `review_status = approved` かつ `membership_status = pending` 等 — Checkout へ         |
| 次回請求日      | `subscription_current_period_end`（列追加後）または Stripe API                         |
| 支払い状態      | `subscription_status` ラベル                                                           |
| Customer Portal | リンク（カード変更・解約・請求確認）                                                   |
| 再契約          | `suspended` / `canceled` 時に Checkout 再開                                            |

## セキュリティ

- Checkout Session は **サーバー** が env の `STRIPE_BREEDER_PRICE_ID` のみ使用
- クライアントから `price_id` / 金額を受け取らない
- 前提: `review_status = approved` をサーバー検証
