## 画面目的

承認済みブリーダーが **月額会費（Stripe Subscription）** の状態確認、Checkout による支払い開始、Customer Portal 経由のカード変更・解約を行う。

## 表示要素

| 要素            | 内容                                                                  |
| --------------- | --------------------------------------------------------------------- |
| プラン          | WithTama ブリーダー会員 / 月額 5,000円（税別）（第1期固定表示）       |
| 会員状態        | `membership_status` を主表示（日本語ラベル）                          |
| 次回更新予定日  | `subscription_current_period_end`（active かつ非解約予約時）          |
| 利用終了予定日  | `subscription_current_period_end`（解約予約中）                       |
| Checkout CTA    | `pending` / `canceled`（審査 approved）→ `POST /api/billing/checkout` |
| Customer Portal | `active` / `suspended` / 解約予約中 → `POST /api/billing/portal`      |

## 導線（Step 6 / 7）

| membership_status   | Checkout     | Portal |
| ------------------- | ------------ | ------ |
| `pending`           | 可           | 不可   |
| `active`            | 不可         | 可     |
| `active` + 解約予約 | 不可         | 可     |
| `suspended`         | 不可         | 可     |
| `canceled`          | 可（再契約） | 不可   |

解約は WithTama 独自 API ではなく **Stripe Customer Portal → Webhook（Step 4/5）** で同期。

## 解約予約表示（`active` + `cancel_at_period_end=true`）

| 項目              | 内容                                                                                                |
| ----------------- | --------------------------------------------------------------------------------------------------- |
| membership_status | **`active` のまま**（期間終了まで利用可能）                                                         |
| 見出し            | 解約予定（`text-amber-800` で通常「利用中」と区別）                                                 |
| 説明文            | `{subscription_current_period_end}に利用終了予定です。解約予定日までは引き続きご利用いただけます。` |
| 日付ラベル        | **利用終了予定日**（「次回更新予定日」は非表示）                                                    |
| Portal ボタン     | 支払い方法を確認・変更（通常契約と同一）                                                            |

### 通常契約（`active` + `cancel_at_period_end=false`）

| 項目       | 内容                                   |
| ---------- | -------------------------------------- |
| 見出し     | 利用中                                 |
| 説明文     | 月額会費のお支払いを確認できています。 |
| 日付ラベル | **次回更新予定日**                     |

### 解約予約・解約取消の実施場所

- **解約予約**（請求期間終了時）: Stripe Customer Portal
- **解約取消**（サブスクを続ける）: Stripe Customer Portal
- WithTama は **Webhook 同期後の DB 値**（`breeders.cancel_at_period_end` 等）を表示
- WithTama 独自の解約取消 API は **作成しない**

## セキュリティ

- Checkout / Portal Session は **サーバー** のみ作成
- クライアントから `price_id` / 金額 / `customer` / `return_url` を受け取らない
- `stripe_customer_id` は DB からサーバー解決（UI 非露出）
- 前提: `review_status = approved` をサーバー検証
