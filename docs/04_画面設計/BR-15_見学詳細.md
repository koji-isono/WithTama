# BR-15 見学詳細

| 項目            | 内容                                               |
| --------------- | -------------------------------------------------- |
| 画面 ID         | BR-15                                              |
| 画面名          | 見学詳細                                           |
| URL             | `/breeder/visits/[visitId]`                        |
| 種別            | 編集 URL（確定・調整・実施記録・完了・キャンセル） |
| 対象ロール      | breeder                                            |
| 状態            | **実装済み**                                       |
| Feature（予定） | `src/features/visits/`                             |
| 認証            | **必須**（breeder layout ガード）                  |
| 共通レイアウト  | `src/app/breeder/layout.tsx`                       |

## 画面目的

ブリーダーが見学希望を **確認・日時確定（または調整）・見学実施記録・完了** する。

現物確認（`animal_confirmed`）と対面説明（`explanation_completed`）は **boolean で実施有無のみ** 記録する（Decision No.58）。実施日時・担当者・電子署名は第1期対象外。

## 上部 — 見学サマリー

| #   | 表示項目         | 備考                           |
| --- | ---------------- | ------------------------------ |
| 1   | 犬猫情報         | 名称・種別等                   |
| 2   | 購入希望者表示名 | **`display_name` のみ**（RPC） |
| 3   | 見学状態         | `visits.status` ラベル         |
| 4   | 希望日時         | 第一〜第三希望                 |
| 5   | 確定日時         | `scheduled_at`                 |
| 6   | 問い合わせ状態   | 参考                           |
| 7   | 問い合わせ開始日 | `inquiries.created_at`         |

### 表示しない buyer 情報（第1期）

BR-12 と同様 — メール・電話・住所は **非表示**（Decision No.112）。

## breeder が実行可能な操作

| visits.status             | 操作       | 処理概要                                                                                                                         |
| ------------------------- | ---------- | -------------------------------------------------------------------------------------------------------------------------------- |
| `requested`               | 日時確定   | RPC `schedule_visit`: `scheduled_at` 設定、`confirmed_by_breeder_at`、`status → scheduled`、`inquiries.status → visit_scheduled` |
| `scheduled`               | 日程調整   | 同一レコードで `scheduled_at` UPDATE（Decision No.57）                                                                           |
| `scheduled`               | 見学完了   | RPC `complete_visit`: 下記「実施記録」+ `completed_at` + `result` + `status → completed` + `inquiries.status → completed`        |
| `requested` / `scheduled` | キャンセル | RPC `cancel_visit`: `status → canceled`、`inquiries.status → replied`                                                            |
| `completed` / `canceled`  | —          | 閲覧のみ（内部メモ `breeder_note` の追記は任意・第1期は簡易 textarea 可）                                                        |

**breeder が更新してはいけない項目（Server / RPC で拒否）:** `requested_at*`（buyer 専用）、`buyer_id` 等（Decision No.123）。

## 日時確定フォーム

| 項目     | 必須                   | 備考                               |
| -------- | ---------------------- | ---------------------------------- |
| 確定日時 | ✅                     | `scheduled_at`。希望日時を参考表示 |
| ボタン   | 「見学日時を確定する」 | RPC `schedule_visit`               |

## 見学完了 — 実施記録フォーム

| 項目     | 必須 | 型       | DB カラム                                            |
| -------- | ---- | -------- | ---------------------------------------------------- |
| 現物確認 | ✅   | checkbox | `animal_confirmed`                                   |
| 対面説明 | ✅   | checkbox | `explanation_completed`                              |
| 見学結果 | ✅   | select   | `result` — `contracted` / `declined` / `considering` |
| 内部メモ | —    | textarea | `breeder_note`                                       |

### `result` の意味（Decision No.122）

| 値            | 意味                                                                                       |
| ------------- | ------------------------------------------------------------------------------------------ |
| `contracted`  | **サイト上で契約した意味ではない**。ブリーダーと購入希望者間で **別途** 行われた結果の記録 |
| `declined`    | 見送り                                                                                     |
| `considering` | 検討中                                                                                     |

犬猫売買契約のサイト内完結・オンライン決済は **行わない**。

| ボタン         | 動作                 |
| -------------- | -------------------- |
| 見学を完了する | RPC `complete_visit` |

**確定日時前の完了制御（Decision No.124）:** `scheduled_at` が未来の間は RPC `complete_visit` を拒否する。UI では「見学を完了する」を disabled にし、補足「見学完了は確定した見学日時以降に記録できます。」を表示する。

**見学結果 select のレイアウト:** 選択肢・補足説明・完了ボタンが重ならないよう、見学結果 select と下部アクション（成約の説明・完了ボタン）を区切り線で分離する。

## 送信処理（設計）

すべて **SECURITY DEFINER RPC**（Decision No.121）。`auth.uid()` で breeder 本人確認。Service Role **不使用**。

| RPC              | 主な副作用                              |
| ---------------- | --------------------------------------- |
| `schedule_visit` | visits + inquiries.status               |
| `complete_visit` | visits + inquiries.status → `completed` |
| `cancel_visit`   | visits + inquiries.status → `replied`   |

## 権限

| ロール  | 操作                                |
| ------- | ----------------------------------- |
| breeder | 本人 `breeder_id` の visit のみ更新 |
| buyer   | アクセス不可                        |
| admin   | 第1期 UI 対象外                     |

## エラー

内部 DB エラーは表示しない。確定日時未入力・完了時 result 未選択等はフィールドエラー。
