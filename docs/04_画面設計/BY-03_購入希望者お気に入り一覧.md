# BY-03 購入希望者お気に入り一覧

| 項目       | 内容                      |
| ---------- | ------------------------- |
| 画面 ID    | BY-03                     |
| 画面名     | お気に入り                |
| URL        | `/buyer/favorites`        |
| 種別       | 表示（一覧）              |
| 対象ロール | buyer                     |
| 状態       | **実装済み**              |
| Feature    | `src/features/favorites/` |

## 目的

購入希望者本人がお気に入り登録した公開中の犬猫を一覧表示し、詳細確認・解除を行う。

## 権限・認証

- `/buyer/*` 共通 layout の `requireBuyer()` を利用
- 未ログイン → `/login`
- breeder / admin → 既存 buyer-auth どおりリダイレクト

## データ取得

1. `auth.uid()` → `buyers.id`
2. `favorites` から本人行を `created_at DESC` で取得
3. `published_pets_public` View と JOIN 相当（アプリ層で `listPublishedPetsForPublicByIds`）
4. 非公開・非掲載 Pet は一覧に表示しない（favorites 行は DB に残る）

## UI

- `SiteHeader` + BY-03 ヘッダー
- PU-01 と同系のカード表示（写真・名称・属性・価格・ブリーダー）
- 「詳細を見る」→ `/pets/[petId]`
- 「お気に入りから外す」→ DELETE
- 0 件時メッセージ + 「犬猫を探す」→ `/pets`

## BY-02 接続

`/buyer/dashboard` の「お気に入り」カード → `/buyer/favorites`

## PU-02 連携

公開犬猫詳細に `FavoriteToggleButton` を配置。

- 未ログイン → `/login?next=/pets/[petId]`
- ログイン buyer → 登録 / 解除トグル

## 第1期スコープ外

ランキング、件数公開、通知、フォルダ、メモ、共有、AI 連携
