# BY-06 購入希望者問い合わせ詳細

| 項目            | 内容                                    |
| --------------- | --------------------------------------- |
| 画面 ID         | BY-06                                   |
| 画面名          | 問い合わせ詳細                          |
| URL             | `/buyer/inquiries/[inquiryId]`          |
| 種別            | 表示 + メッセージ送信（編集 URL）       |
| 対象ロール      | buyer                                   |
| 状態            | **設計確定・実装済み**                  |
| Feature（予定） | `src/features/inquiries/`               |
| 認証            | **必須**                                |
| 共通レイアウト  | `(buyer)/layout.tsx` — `requireBuyer()` |

## 画面目的

購入希望者本人の問い合わせについて、**メッセージ履歴の閲覧** と **追加メッセージ送信** を行う。

第1期は **非同期メッセージ方式**。LINE 等のリアルタイムチャット UI は採用しない。

## 遷移

| 入口                         | 遷移元   |
| ---------------------------- | -------- |
| BY-04 初回送信成功           | redirect |
| BY-05「詳細を見る」          | 一覧     |
| PU-02（有効 inquiry 再利用） | redirect |
| BY-07 見学希望送信成功       | BY-09 へ（visit 経由で inquiry 表示） |

## 見学導線（Decision No.118）

問い合わせに **active visit がない** 場合、サマリー下部に **「見学を希望する」** ボタンを表示する。

| 条件 | ボタン |
| ---- | ------ |
| visit なし、`inquiries.status` が `open` または `replied` | 「見学を希望する」→ BY-07 |
| visit あり（`deleted_at IS NULL`） | 「見学詳細を見る」→ BY-09 |
| visit が `canceled`（1 inquiry 1 visit のため再希望不可） | 「見学詳細を見る」のみ → BY-09 |
| `closed` / `completed` かつ visit なし | ボタン非表示 |

## 上部 — 問い合わせサマリー

| #   | 表示項目           | データソース           |
| --- | ------------------ | ---------------------- |
| 1   | 犬猫写真           | pet メイン写真         |
| 2   | 犬猫名             | `public_display_name`  |
| 3   | ブリーダー表示名   | `business_name`        |
| 4   | 問い合わせ状態     | status 日本語ラベル    |
| 5   | 問い合わせ開始日時 | `inquiries.created_at` |

**犬猫が非公開化後:** サマリーは **既存 inquiry に紐づく pet 情報を表示し続ける**（Decision No.115）。詳細リンク `/pets/[petId]` は pet が非公開の場合 disabled または非表示。

## メッセージ履歴

| 表示項目 | 内容                                                         |
| -------- | ------------------------------------------------------------ |
| 送信者   | 「あなた」/ 「ブリーダー」等のラベル（buyer / breeder 区別） |
| 本文     | `inquiry_messages.message`（改行保持）                       |
| 送信日時 | `created_at`                                                 |

### UI 方針

- 時系列昇順（古い → 新しい）
- buyer / breeder で **背景色または左右寄せ** を変え、会話であることを示す
- 吹き出しは軽量に。過度なチャット UI（入力中インジケータ・既読リアルタイム表示等）は **第1期禁止**
- admin メッセージ（将来）— 第1期 UI では非表示または「運営」とラベル（発生時のみ）

## 下部 — 追加メッセージ

| 項目     | 仕様                                   |
| -------- | -------------------------------------- |
| 入力     | textarea（BY-04 と同じバリデーション） |
| ボタン   | 「送信する」                           |
| 二重送信 | 送信中 disabled + 「送信中…」          |

### 送信不可 status

以下の status では **入力欄を非表示**（または disabled + 説明文）:

| status      | 入力欄 | 説明文案（例）                   |
| ----------- | ------ | -------------------------------- |
| `closed`    | 非表示 | この問い合わせは終了しています。 |
| `completed` | 非表示 | この問い合わせは完了しています。 |

以下は **送信可能**（第1期）:

`open`, `replied`, `visit_requested`, `visit_scheduled`

**見学キャンセル後** `inquiries.status = replied` に戻るため、メッセージ送信は **継続可能**（Decision No.119）。

`visit_*` status は見学 RPC で設定。問い合わせ UI から status を **直接変更しない**。

## 送信処理（追加メッセージ）

1. inquiry が本人の buyer に属することを Server 確認
2. status が送信可能であることを確認
3. `inquiry_messages` INSERT（`sender_type = buyer`）
4. `inquiries.last_message_at` 更新
5. 必要に応じ `status` を `open` に維持（初回以降 buyer 送信で status 変更は原則不要）
6. 画面 revalidate / redirect で履歴更新

## 既読

[Decision No.116](../01_設計変更管理/DecisionLog.md#decision-no116) を参照。

詳細画面を buyer が開いた時点で、**ブリーダー送信分の未読**（`sender_type = breeder`, `is_read = false`）を Server Action で既読化する。

- リアルタイム既読通知 UI は **不要**
- UPDATE は `is_read` / `read_at` のみ

## 権限

| ロール              | 操作                                    |
| ------------------- | --------------------------------------- |
| buyer               | 本人 inquiry の閲覧・本人メッセージ送信 |
| breeder             | アクセス不可                            |
| 未ログイン          | `/login?next=/buyer/inquiries/[id]`     |
| 他 buyer の inquiry | 404（RLS 0 件と同等 UX）                |

## エラー・例外

| ケース                    | 方針                                 |
| ------------------------- | ------------------------------------ |
| inquiry 不存在            | 404                                  |
| 他人の inquiry            | 404                                  |
| closed / completed へ送信 | 「この問い合わせには返信できません」 |
| 空本文                    | フィールドエラー                     |
| 送信失敗                  | 汎用エラー。入力値維持               |

## レスポンシブ

| デバイス       | レイアウト                                                                            |
| -------------- | ------------------------------------------------------------------------------------- |
| スマートフォン | サマリー → スクロール可能メッセージ領域 → **下部固定** 入力フォーム（キーボード考慮） |
| PC             | サマリー上部。メッセージ + 入力は `max-w-3xl` 中央。入力はメッセージ下                |
