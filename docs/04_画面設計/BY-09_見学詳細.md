# BY-09 見学詳細

| 項目            | 内容                                    |
| --------------- | --------------------------------------- |
| 画面 ID         | BY-09                                   |
| 画面名          | 見学詳細                                |
| URL             | `/buyer/visits/[visitId]`               |
| 種別            | 表示 + 限定更新（希望変更・キャンセル） |
| 対象ロール      | buyer                                   |
| 状態            | **設計確定・未実装**                    |
| Feature（予定） | `src/features/visits/`                  |
| 認証            | **必須**                                |
| 共通レイアウト  | `(buyer)/layout.tsx` — `requireBuyer()` |

## 画面目的

購入希望者本人の見学について、**希望・確定日時・状態** を確認し、`status = requested` 中は希望日時の変更・キャンセル、`scheduled` 中はキャンセルのみ可能とする。

メッセージのやり取りは **BY-06 問い合わせ詳細** で継続する（見学キャンセル後も `inquiries.status = replied` となり送信可能 — Decision No.119）。

## 上部 — 見学サマリー

| #   | 表示項目         | データソース |
| --- | ---------------- | ------------ |
| 1   | 犬猫写真         | pet メイン写真 |
| 2   | 犬猫名           | `public_display_name` |
| 3   | ブリーダー名     | `business_name` |
| 4   | 見学状態         | `visits.status` ラベル |
| 5   | 第一希望日時     | `requested_at` |
| 6   | 第二希望日時     | `requested_at_second`（あれば） |
| 7   | 第三希望日時     | `requested_at_third`（あれば） |
| 8   | 確定日時         | `scheduled_at`（`scheduled` 以降） |
| 9   | 見学結果         | `result` ラベル（`completed` 時） |
| 10  | 問い合わせ状態   | `inquiries.status` ラベル |

**実施記録（`completed` 時）:** `animal_confirmed` / `explanation_completed` を **実施済み / 未実施** で表示（buyer は閲覧のみ）。

## 導線

| リンク | 先 |
| ------ | -- |
| 問い合わせ詳細を見る | BY-06 `/buyer/inquiries/[inquiryId]` |
| 見学予定一覧へ戻る | BY-08 `/buyer/visits` |

## buyer が実行可能な操作

| visits.status | 操作 | 処理 |
| ------------- | ---- | ---- |
| `requested`   | 希望日時変更 | RPC / Server Action。`requested_at*` のみ UPDATE |
| `requested`   | キャンセル | RPC `cancel_visit`。`visits.status → canceled`、`inquiries.status → replied` |
| `scheduled`   | キャンセル | 同上 |
| `completed`   | — | 閲覧のみ |
| `canceled`    | — | 閲覧のみ。BY-06 でメッセージ継続可 |

**buyer が更新してはいけない項目（Server / RPC で拒否）:** `scheduled_at`, `animal_confirmed`, `explanation_completed`, `result`, `breeder_note`, `confirmed_by_breeder_at`, `completed_at` 等（Decision No.123）。

### キャンセル UI

| 項目 | 仕様 |
| ---- | ---- |
| ボタン | 「見学をキャンセルする」（destructive 系） |
| 理由 | `cancellation_reason` — **任意** textarea（第1期） |
| 確認 | 簡易確認ダイアログ |

キャンセル後: `inquiries.status = replied` のため **問い合わせは終了せず** メッセージ送信を継続できる（Decision No.119）。

## 権限

| ロール              | 操作 |
| ------------------- | ---- |
| buyer               | 本人 visit の閲覧・上記限定更新 |
| breeder             | アクセス不可（BR-15 を使用） |
| 未ログイン          | `/login?next=...` |
| 他 buyer の visit   | 404 |

## エラー・例外

| ケース | 方針 |
| ------ | ---- |
| visit 不存在 | 404 |
| 完了済みへの変更 | 「この見学は変更できません」 |
| キャンセル失敗 | 汎用エラー |
