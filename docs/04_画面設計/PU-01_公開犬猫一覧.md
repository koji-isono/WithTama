# PU-01 公開犬猫一覧

| 項目           | 内容                                              |
| -------------- | ------------------------------------------------- |
| 画面 ID        | PU-01                                             |
| 画面名         | 公開犬猫一覧                                      |
| 画面 URL       | `/pets`                                           |
| 種別           | 表示（一覧）。詳細は `/pets/[petId]`（別工程）    |
| 状態           | **設計確定**（未実装）                            |
| 実装ファイル   | `src/app/(public)/pets/page.tsx`（予定）          |
| Feature        | `src/features/pets/`（公開向け loader / UI 追加） |
| 認証           | **不要**（未ログイン閲覧可）                      |
| 共通レイアウト | `src/app/(public)/layout.tsx`                     |

## 画面目的

購入希望者および未ログインユーザーが、**管理者承認済み（`status = published`）** の犬猫を一覧で閲覧し、気になる個体の詳細へ進める入口とする。

## 第1期スコープ

### 含む

- `published` かつ `deleted_at IS NULL` の犬猫のみ表示
- Card 形式の一覧（レスポンシブグリッド）
- メイン写真（Signed URL）
- 公開表示名・基本属性・価格・ブリーダー屋号・都道府県
- 詳細ページへのリンク（詳細本体は PU-02 別工程）

### 含まない（第1期）

- 検索・絞り込み（犬猫種別 / 品種 / 地域 / 価格帯 等）
- ソート UI（表示順はサーバー側固定。具体値は [§表示順](#表示順) 参照）
- お気に入り登録
- 問い合わせ導線（PU-02 / 問い合わせ機能と連動）
- ブリーダー詳細ページへのリンク（**未決定** — 第1期に含めるか）
- ページネーション（件数が少ない間は全件表示。**件数上限は未決定**）

## 使用コンポーネント

| コンポーネント | 用途                              |
| -------------- | --------------------------------- |
| Card           | 犬猫 1 件分のカード               |
| Badge          | 犬 / 猫 種別（任意・**未決定**）  |
| Button / Link  | 「詳細を見る」                    |
| `ImageOff` 等  | 写真なしフォールバック（参考 UI） |

既存 `src/features/pets/components/breeder-pets-list-content.tsx` の Card レイアウトを **参考** とするが、管理名・status Badge・公開申請 UI は **含めない**。

## 公開してはいけない情報

以下は PU-01 に **表示・API レスポンス・HTML 出力してはならない**。

### 犬猫（pets）

| 区分       | カラム / 情報                                                             |
| ---------- | ------------------------------------------------------------------------- |
| 内部管理   | `management_name`                                                         |
| 内部 ID    | `breeder_id`（HTML data 属性等への露出も避ける）                          |
| 監査       | `created_by`, `updated_by`, `created_at`, `updated_at`                    |
| 内部状態   | `status`（一覧に draft / under_review 等を出さない）                      |
| 非公開個体 | `status != published`、`deleted_at IS NOT NULL` の全件                    |
| AI 下書き  | `ai_description`, `ai_generated_at`                                       |
| 詳細属性   | `color`, `temperament`, `description`, `price_comment`（PU-02 で検討）    |
| 掲載メタ   | `display_order`, `published_at`（カード非表示。ソート用のみサーバー内部） |

**注意:** 現行 RLS `pets_select_public_published` は行単位 SELECT のため、PostgREST 直接呼び出しでは `management_name` 等も読める。**アプリは公開カラムのみ SELECT し、Migration では [設計書](../09_開発履歴/2026-08-14_PU-01_公開犬猫一覧_設計.md) の View 追加を推奨**（第1期実装時）。

### 写真（pet_photos / Storage）

| 区分             | 内容                                                                                          |
| ---------------- | --------------------------------------------------------------------------------------------- |
| 非公開犬猫の写真 | `status != published` または `deleted_at IS NOT NULL` の Pet に紐づく行・Storage オブジェクト |
| 内部パス         | `storage_path` を HTML に生露出しない（Signed URL のみ）                                      |
| バケット公開化   | `pet-photos` バケットを `public = true` にしない                                              |

### ブリーダー（breeders）

| 区分             | カラム / 情報                                                                   |
| ---------------- | ------------------------------------------------------------------------------- |
| 認証             | `user_id`                                                                       |
| 個人             | `representative_name`, `phone`                                                  |
| 住所詳細         | `postal_code`, `address_line`                                                   |
| 書類             | `identity_document_path`, `business_license_path`                               |
| 審査内部         | `review_status`, `identity_verification_status`, `business_verification_status` |
| 課金             | `stripe_*`, `subscription_status`, `membership_status`                          |
| 登録詳細         | `business_registration_number`, `registration_expires_at` 等（一覧非表示）      |
| 長文プロフィール | `profile_text`, `breeding_policy` 等（PU-02 / ブリーダー詳細で表示）            |

### その他

| 区分         | 内容                            |
| ------------ | ------------------------------- |
| 審査履歴     | `pet_review_logs` 全般          |
| 認証ユーザー | `auth.users` のメールアドレス等 |

## データ取得条件

| 条件               | 内容                                             |
| ------------------ | ------------------------------------------------ |
| Pet status         | `published` のみ                                 |
| 論理削除           | `pets.deleted_at IS NULL`                        |
| ブリーダー         | `breeders.deleted_at IS NULL`（JOIN 時）         |
| ブリーダー審査状態 | **未決定** — 承認済みブリーダーのみに限定するか  |
| 写真               | 対象 Pet が published のときのみ Signed URL 発行 |

## 表示順

| 項目     | 第1期案                             | 状態       |
| -------- | ----------------------------------- | ---------- |
| 主ソート | `published_at DESC`（新しい公開順） | **未決定** |
| 副ソート | `created_at DESC`                   | **未決定** |

Decision / 要件定義に公開一覧のソート規定は **現時点なし**。実装前に Decision 追記を推奨。

| 条件                  | 表示                                             |
| --------------------- | ------------------------------------------------ |
| published Pet が 0 件 | 「現在公開中の犬猫はありません。」等のメッセージ |
| 写真なし              | プレースホルダー（アイコン + 背景色）            |

文言の最終確定は **未決定**（実装時に UX 調整可）。

## エラー・異常系

| ケース                  | 方針                                                                            |
| ----------------------- | ------------------------------------------------------------------------------- |
| DB / Storage 取得失敗   | Server Component で error boundary または汎用エラー表示（**詳細設計は未決定**） |
| Signed URL 生成失敗     | 当該 Card のみ写真プレースホルダー                                              |
| published だが写真 0 枚 | 公開申請要件上通常あり得ないが、プレースホルダー表示                            |

## データ取得アーキテクチャ（概要）

詳細は [PU-01 設計書](../09_開発履歴/2026-08-14_PU-01_公開犬猫一覧_設計.md) を参照。

| レイヤー   | 責務                                                              |
| ---------- | ----------------------------------------------------------------- |
| Page       | `src/app/(public)/pets/page.tsx` — Server Component               |
| Loader     | `loadPublicPetsPage()` — 公開一覧 DTO 組み立て                    |
| Repository | `listPublishedPetsForPublic()` — Supabase SELECT + Signed URL     |
| Supabase   | anon / publishable key + **公開 READ 用 RLS / View**（Migration） |

- 認証セッション不要（`createClient()` を未ログイン状態で使用）
