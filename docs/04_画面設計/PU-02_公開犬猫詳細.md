## 画面目的

購入希望者および未ログインユーザーが、**公開条件を満たす犬猫 1 件**について、写真・基本属性・性格・紹介文・育てているブリーダーの考え方を、WithTama のブランドに沿った情報設計で閲覧する。

EC 商品詳細のような「価格中心」の見せ方は避け、**出会ったその日から、命は家族になる。** という考え方が自然に伝わる構成とする。

## 第1期スコープ

### 含む

- 公開条件を満たす Pet のみ表示（条件不一致は **404**）
- Public Header + 「犬猫一覧へ戻る」導線
- スマートフォン優先の写真ギャラリー（Signed URL・複数枚）
- 犬猫基本情報（公開カラムのみ）
- 「この子について」（性格・気質 / 紹介文）
- 「ブリーダーについて」（屋号・所在地・方針テキスト群）
- レスポンシブ（スマホ 1 カラム / PC 2 カラム相当）
- アクセシビリティ（見出し階層・alt・キーボード・可読性）

## 写真ギャラリー

### 方針

| 項目         | 内容                                                             |
| ------------ | ---------------------------------------------------------------- |
| バケット     | `pet-photos` は **private 維持**（public 化しない）              |
| 表示方法     | Server 側で Signed URL 生成し、クライアントへ URL のみ渡す       |
| 露出禁止     | `storage_path` を HTML / JSON-LD / data 属性に **出力しない**    |
| 枚数         | 複数写真対応（0 枚時はプレースホルダー）                         |
| 並び順       | `is_main = true` を先頭 → `display_order ASC` → `created_at ASC` |
| Service Role | **不使用**（anon + RLS + 既存 Storage ポリシー）                 |

### スマートフォン UI（優先設計）

| 要素         | 仕様                                                                                          |
| ------------ | --------------------------------------------------------------------------------------------- |
| メイン領域   | 画面幅いっぱい（左右パディング最小）。アスペクト比 **4:3** または **1:1**（実装時 UX 調整可） |
| 操作         | 左右スワイプで前後の写真へ。矢印ボタンは PC / キーボード向けに併設                            |
| インジケータ | ドットまたは「2 / 5」形式。現在位置をテキストでも補足（色のみに依存しない）                   |
| サムネイル列 | 2 枚以上のとき、メイン下に横スクロールサムネイル（タップで選択）                              |
| 1 枚のみ     | スワイプ・サムネイル非表示                                                                    |
| 0 枚         | プレースホルダー（`ImageOff` + 背景色）。文言例:「写真は準備中です」                          |

### PC UI

- メイン写真を左カラムに大きく配置
- サムネイル列はメイン下または左端縦列（実装時いずれか。横スクロールサムネイルを基本とする）
- キーボード: 左右矢印で写真切替、サムネイルは Tab フォーカス可能

### alt テキスト

| 条件 | alt 内容（例）                                       |
| ---- | ---------------------------------------------------- |
| 通常 | `{public_display_name}の写真（{index}/{total}）`     |
| 0 枚 | 装飾的プレースホルダー — `alt=""` または「写真なし」 |

## 犬猫基本情報（表示項目）

| #   | 表示ラベル（UI） | データソース          | 備考                                                                 |
| --- | ---------------- | --------------------- | -------------------------------------------------------------------- |
| 1   | 公開表示名       | `public_display_name` | ページ `h1`。**管理名は表示しない**（Decision No.31）                |
| 2   | 犬猫種別         | `species`             | `dog` → 犬、`cat` → 猫                                               |
| 3   | 品種             | `breed`               | 自由入力                                                             |
| 4   | 性別             | `sex`                 | `male` / `female`（既存 label 関数）                                 |
| 5   | 月齢             | `birthday`            | 「Nか月」。NULL は「未登録」（PU-01 と同じ helper）                  |
| 6   | 毛色             | `color`               | NULL / 空文字は **項目ごと非表示**                                   |
| 7   | 価格             | `price`               | `formatPetPrice` 相当。NULL は「価格未設定」。**視覚的主役にしない** |
| 8   | 価格補足         | `price_comment`       | NULL / 空文字は **非表示**                                           |

### 基本属性行（案）

属性 2〜5 を 1 行に連結表示（PU-01 カードと同型）:

```
犬 · トイプードル · 女の子 · 3か月
```

区切りは中点 `·`。価格は別行とし、font-weight を本文より一段弱くする（EC の大きな価格表示は避ける）。

## 「この子について」

| 項目       | データソース  | 表示条件                       |
| ---------- | ------------- | ------------------------------ |
| 性格・気質 | `temperament` | 非 NULL かつ trim 後が空でない |
| 紹介文     | `description` | 同上                           |

- セクション見出し: `h2`「この子について」
- 各サブ見出し: `h3`（「性格・気質」「紹介文」）
- 改行は `whitespace-pre-wrap` 等で保持
- **`ai_description` / `ai_generated_at` は絶対に表示しない**（Server / Client いずれも DTO に含めない）

両方空の場合: セクション全体を **非表示**（空の見出しだけ出さない）。

## 公開条件と 404

### 表示対象（すべて満たすこと）

| 条件               | 内容                          |
| ------------------ | ----------------------------- |
| Pet status         | `published`                   |
| Pet 論理削除       | `deleted_at IS NULL`          |
| ブリーダー論理削除 | `breeders.deleted_at IS NULL` |
| ブリーダー審査     | `review_status = approved`    |
| ブリーダー会員     | `membership_status = active`  |

実装では PU-01 と同様、`is_publicly_listable_pet(pet_id)` および詳細用 View で判定する。

### 404 とするケース

| ケース                                              | HTTP |
| --------------------------------------------------- | ---- |
| 存在しない UUID                                     | 404  |
| 不正な UUID 形式（ルート param バリデーション失敗） | 404  |
| `status != published`（draft, under_review 等）     | 404  |
| `deleted_at IS NOT NULL`                            | 404  |
| ブリーダーが公開条件を満たさない                    | 404  |
| View / RPC が 0 行                                  | 404  |

**403 は使わない** — 非公開個体の存在を推測させないため、未公開・不存在は同一く 404（`notFound()`）。

UUID バリデーションは既存 `pet-id` 等のパターンに合わせる（実装工程）。

## データ取得アーキテクチャ（概要）

[実装前調査](../09_開発履歴/2026-08-14_PU-02_公開犬猫詳細_実装前調査.md) に基づく推奨構成。

| レイヤー   | 責務                                                                      |
| ---------- | ------------------------------------------------------------------------- |
| Page       | `src/app/(public)/pets/[petId]/page.tsx` — Server Component, `notFound()` |
| Loader     | `loadPublicPetDetailPage(petId)` — 詳細 DTO 組み立て                      |
| Repository | `getPublishedPetDetailForPublic(petId)` — View SELECT + 写真 Signed URL   |
| Supabase   | anon + **詳細用 View**（Migration 追加予定）                              |

### 推奨 View（実装工程で Migration）

| View 名                          | 用途                                                                                    |
| -------------------------------- | --------------------------------------------------------------------------------------- |
| `published_pet_detail_public`    | 詳細用 Pet 公開列（一覧 View + `color`, `temperament`, `description`, `price_comment`） |
| `breeder_public_detail_profiles` | 詳細用ブリーダー公開列（一覧 View + `city`, `profile_text`, 各種 policy）               |

- **Service Role 不使用**
- **Server Action 不要**（読み取り専用）
- `force-dynamic` または Signed URL TTL を考慮した再検証方針（キャッシュ最適化は第1期スコープ外）
- RLS 緩和は **行わない**（既存 `is_publicly_listable_pet` + Storage ポリシーを利用）

### DTO（案）

Server のみで扱う。Client へ渡す props には公開列 + Signed URL のみ。

```
PublicPetDetailPageData {
  pet: { id, publicDisplayName, species, breed, sex, birthday, color,
         temperament?, description?, price, priceComment? }
  photos: { id, signedUrl, alt }[]   // storage_path なし
  breeder: { businessName?, prefecture?, city?, profileText?,
             breedingPolicy?, healthPolicy?, breedingEnvironment? }
}
```
