## 1. RLS 事前確認

実装前に `pet_review_logs` の admin SELECT 可否を Migration 定義で確認した。

| テーブル / リソース  | ポリシー                          | admin SELECT | 備考                         |
| -------------------- | --------------------------------- | ------------ | ---------------------------- |
| `pets`               | `pets_select_admin`               | ✅           | `status = under_review` 取得 |
| `breeders`           | admin 向け SELECT                 | ✅           | JOIN でブリーダー名          |
| `pet_review_logs`    | `pet_review_logs_select_admin`    | ✅           | `public.is_admin()`          |
| `pet_photos`         | `pet_photos_select_admin`         | ✅           | メイン写真                   |
| Storage `pet-photos` | `pet_photos_storage_select_admin` | ✅           | Signed URL 生成              |

**結論:** `pet_review_logs` の `action = 'submitted'` は admin から SELECT 可能。RLS / Migration の追加変更は不要と判断し、実装を継続した。

参照 Migration: `supabase/migrations/20260807110000_create_pet_review_logs.sql`（50–54 行目 `pet_review_logs_select_admin`）

## 4. データ取得・表示仕様

### 取得条件

```sql
pets.status = 'under_review'
AND pets.deleted_at IS NULL
```

### 表示項目（AD-10 設計書準拠）

| 項目         | データソース                                                  |
| ------------ | ------------------------------------------------------------- |
| メイン写真   | `pet_photos`（`is_main = true`）+ Signed URL                  |
| 公開表示名   | `pets.public_display_name`                                    |
| 品種         | `pets.breed`                                                  |
| ブリーダー名 | `breeders.business_name` → なければ `representative_name`     |
| 申請日時     | `pet_review_logs` 最新 `action = 'submitted'` の `created_at` |
| 詳細ボタン   | `/admin/pets/reviews/[petId]` へリンク                        |

### ソート順

- **申請日時の新しい順**（実装指示に従った）
- submitted ログが無い行は末尾（同一グループ内は公開表示名で tie-break）
- 設計書 Decision No.106（古い順）とは異なる点に注意

### 申請日時不明

- `pet_review_logs` に `submitted` が存在しない既存データは、画面エラーにせず **「申請日時不明」** と表示

### 詳細 URL（AD-11 向け設計）

```text
/admin/pets/reviews/{petId}
```

ヘルパー: `getAdminPetReviewDetailPath(petId)`（`src/features/admin/constants.ts`）
