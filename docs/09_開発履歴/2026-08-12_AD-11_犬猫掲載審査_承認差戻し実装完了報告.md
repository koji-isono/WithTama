## 3. 既存 RPC 仕様（Migration 確認・事実）

### `approve_pet_for_publish(p_pet_id uuid)`

| 項目           | 内容                                                                                                                                                                           |
| -------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| 戻り値         | `void`                                                                                                                                                                         |
| 権限           | `authenticated` + RPC 内 `is_admin()`                                                                                                                                          |
| 前提           | `pets.status = under_review`、`deleted_at IS NULL`                                                                                                                             |
| ブリーダー条件 | `review_status = approved`、`identity_verification_status = verified`、`business_verification_status = verified`、`registration_expires_at IS NOT NULL` かつ `>= CURRENT_DATE` |
| 更新           | `status = published`、`published_at = now()`                                                                                                                                   |
| ログ           | `pet_review_logs` INSERT `action = approved`、`comment = NULL`                                                                                                                 |

**例外メッセージ（RAISE EXCEPTION）:** `pet id is required` / `authentication required` / `admin required` / `pet not found` / `invalid pet status` / `breeder not eligible for publication`

### `return_pet_review(p_pet_id uuid, p_comment text)`

| 項目     | 内容                                                                       |
| -------- | -------------------------------------------------------------------------- |
| 戻り値   | `void`                                                                     |
| 権限     | 同上                                                                       |
| コメント | `btrim(p_comment)` が空なら `return comment required`                      |
| 前提     | `status = under_review`、`published_at IS NULL`                            |
| 更新     | `status = draft`                                                           |
| ログ     | `pet_review_logs` INSERT `action = returned`、`comment = btrim(p_comment)` |

**例外メッセージ:** 上記に加え `published_at inconsistency`

### 二重実行（Migration 確認・事実）

- 承認・差戻しとも `FOR UPDATE` + `status = under_review` 条件 UPDATE
- 処理後は `under_review` 以外になるため、同一 Pet への再実行は `invalid pet status` で拒否

## 6. 承認フロー

```
[管理者] AD-11 詳細で「承認して公開」クリック
    ↓
確認ダイアログ表示
    ↓
approvePetForPublishAction(petId)
    ↓ requireAdmin()
    ↓ validatePetIdForAdminReview()
    ↓ approvePetForPublishViaRpc() → .rpc("approve_pet_for_publish", { p_pet_id })
    ↓ revalidatePath(/admin/pets/reviews, /admin/pets/reviews/[petId])
    ↓
成功 → router.push(/admin/pets/reviews) + refresh
失敗 → ダイアログ内エラー表示（成功扱いにしない）
```

**RPC 内結果:** `under_review` → `published` + `published_at` + `pet_review_logs(approved)`

---

## 7. 差戻しフロー

```
[管理者] 差戻し理由入力 →「差戻し」クリック（trim 空ならボタン disabled）
    ↓
確認ダイアログ表示
    ↓
returnPetReviewAction(petId, comment)
    ↓ requireAdmin()
    ↓ validatePetId + validateReturnReviewComment (trim 後非空)
    ↓ returnPetReviewViaRpc() → .rpc("return_pet_review", { p_pet_id, p_comment: trim(comment) })
    ↓ revalidatePath
    ↓
成功 → 一覧へ遷移
失敗 → エラー表示
```

**RPC 内結果:** `under_review` → `draft` + `pet_review_logs(returned, comment)`

## 8. Server Action 仕様

| Action                       | 引数                               | 戻り値                                                     |
| ---------------------------- | ---------------------------------- | ---------------------------------------------------------- |
| `approvePetForPublishAction` | `petId: string`                    | `{ success: true }` \| `{ success: false, error: string }` |
| `returnPetReviewAction`      | `petId: string`, `comment: string` | 同上                                                       |

**処理順:** `requireAdmin()` → 入力検証 → RPC → `revalidatePath` → 結果返却

**redirect:** Server Action 内では `redirect()` を使わず、Client 側で `router.push(ADMIN_PET_REVIEWS_PATH)`（エラー時に結果を返す必要があるため）。

---

## 9. 入力検証

| 層            | 承認                 | 差戻し                             |
| ------------- | -------------------- | ---------------------------------- |
| UI            | 確認ダイアログ       | コメント trim 空 → ボタン disabled |
| Server Action | UUID 形式・非空      | 同上 + `comment.trim().length > 0` |
| RPC           | `p_pet_id` NULL 拒否 | `btrim(p_comment)` 空拒否          |

## 10. エラー処理

| RPC 例外（部分一致）                         | ユーザー向けメッセージ                  |
| -------------------------------------------- | --------------------------------------- |
| `admin required` / `authentication required` | 管理者権限が必要です。                  |
| `pet not found`                              | 対象の犬猫が見つかりません。            |
| `invalid pet status`                         | 審査対象外（処理済みの可能性）          |
| `breeder not eligible for publication`       | ブリーダー条件未充足                    |
| `return comment required`                    | 差戻し理由を入力してください。          |
| その他                                       | 汎用エラー（内部 SQL / stack は非表示） |

開発時のみ `console.error`（`NODE_ENV === development`）。
