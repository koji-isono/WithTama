## 1. 概要

一般公開 `/pets` に、**公開 READ 基盤（View + RLS + Signed URL）** を利用した犬猫カード一覧を実装した。

- **認証不要**（anon / publishable key 経路）
- **Service Role 不使用**
- **Storage bucket public 化なし**
- **`pets` 非公開列を SELECT しない**（`published_pets_public` View のみ）

---

## 2. 実装内容

### 2.1 データ取得

| レイヤー   | ファイル                                 | 責務                                             |
| ---------- | ---------------------------------------- | ------------------------------------------------ |
| Repository | `src/features/pets/public-repository.ts` | View から公開 Pet 一覧 + ブリーダー + Signed URL |
| Loader     | `src/features/pets/loaders.ts`           | `loadPublicPetsPage()`                           |
| Page       | `src/app/(public)/pets/page.tsx`         | Server Component（`force-dynamic`）              |

**SELECT 対象:**

| ソース                    | 列                                                                                                                  |
| ------------------------- | ------------------------------------------------------------------------------------------------------------------- |
| `published_pets_public`   | `id`, `public_display_name`, `species`, `breed`, `sex`, `birthday`, `price`, `breeder_id`（サーバー内部 JOIN のみ） |
| `breeder_public_profiles` | `id`, `business_name`, `prefecture`                                                                                 |
| `pet_photos`              | `pet_id`, `storage_path`（`is_main = true`）                                                                        |
| Storage `pet-photos`      | Signed URL（300 秒）                                                                                                |

### 2.2 UI

| コンポーネント | ファイル                                            |
| -------------- | --------------------------------------------------- |
| 一覧           | `src/features/pets/components/public-pets-list.tsx` |
| カード         | `src/features/pets/components/public-pet-card.tsx`  |

**カード表示項目（第1期）:**

- メイン写真（Signed URL / プレースホルダー）
- 公開表示名
- 犬猫種別 · 品種 · 性別 · 月齢
- 価格
- ブリーダー屋号（都道府県）
- 「詳細を見る」（カード全体リンク → `/pets/[petId]`）

**レスポンシブ:** 1 列（スマホ）/ 2 列（タブレット）/ 3 列（PC、`max-w-6xl`）

### 2.3 表示フォーマット

`src/features/pets/list-format.ts` に PU-01 用 helper を追加:

- `getPublicSexLabel` — 男の子 / 女の子
- `formatPublicPetAge` — Nか月（NULL → 未登録）
- `formatPublicPetAttributeLine`
- `formatPublicBreederLocation`

## 3. 設計との整合 / 報告事項

| 項目                 | 状態                      | 備考                                                                                                                                                 |
| -------------------- | ------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------- |
| View 経由の公開 READ | ✅                        | Migration 済みポリシーをそのまま利用                                                                                                                 |
| 非公開列非露出       | ✅                        | View 列 + DTO のみ。HTML に `breeder_id` / `storage_path` なし                                                                                       |
| Signed URL           | ✅                        | 既存 `PET_PHOTO_SIGNED_URL_EXPIRES_SECONDS = 300`                                                                                                    |
| 検索・絞り込み       | ✅ 未実装                 | 設計どおり第1期スコープ外                                                                                                                            |
| `/pets/[petId]` 詳細 | ⏳ プレースホルダーのまま | PU-02 別工程                                                                                                                                         |
| **一覧ソート**       | ⚠️ 暫定                   | 設計未決定。View に `published_at` が無いため **`public_display_name ASC`** で固定。`published_at DESC` にする場合は View 拡張 + Decision 追記が必要 |
| ブリーダー詳細リンク | ✅ 未実装                 | 設計「未決定」どおり                                                                                                                                 |
| `business_name` NULL | 暫定「名称未設定」        | 設計未決定項目                                                                                                                                       |

**設計矛盾による勝手な変更はなし。** ソートのみ View 制約に伴う暫定実装（上記）。
