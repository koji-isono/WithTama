## 1. 概要

`published_pet_detail_public` / `breeder_public_detail_profiles` を利用し、未ログイン閲覧可能な公開犬猫詳細画面を実装した。

- **Service Role 不使用**
- **公開 DTO / HTML に `breeder_id`・`storage_path`・内部列を含めない**
- 問い合わせ・見学・お気に入り・ダミーボタンは **未実装**（設計どおり）

## 3. 実装内容

### Repository

| 関数                                    | ファイル                                 | 内容                                                                                      |
| --------------------------------------- | ---------------------------------------- | ----------------------------------------------------------------------------------------- |
| `getPublishedPetDetailForPublic(petId)` | `src/features/pets/public-repository.ts` | 詳細 View SELECT → ブリーダー詳細 View JOIN → 複数写真 Signed URL → `PublicPetDetail` DTO |

- 写真並び: `is_main` 優先 → `display_order` → `created_at`
- `breeder_id` は Repository 内 JOIN のみ。DTO へはマッピングしない

### Loader

| 関数                             | ファイル                       | 内容                                                                   |
| -------------------------------- | ------------------------------ | ---------------------------------------------------------------------- |
| `loadPublicPetDetailPage(petId)` | `src/features/pets/loaders.ts` | UUID バリデーション → 404 / エラー / 成功を discriminated union で返却 |

### UI

| ファイル                                 | 内容                                               |
| ---------------------------------------- | -------------------------------------------------- |
| `src/app/(public)/pets/[petId]/page.tsx` | Server Component、`force-dynamic`、`notFound()`    |
| `public-pet-detail-view.tsx`             | レイアウト・セクション（この子 / ブリーダー）      |
| `public-pet-photo-gallery.tsx`           | クライアント写真切替（矢印・サムネイル・分数表示） |

### 型・ユーティリティ

- `PublicPetDetail`, `PublicBreederDetail`, `PublicPetDetailPhoto` — `types.ts`
- `isValidPublicPetId` — `validation.ts`
- `formatPublicBreederAddress`, `formatPublicPetPhotoAlt` — `list-format.ts`
