## 確定した仕様

### URL・対象

| 項目         | 内容                              |
| ------------ | --------------------------------- |
| URL          | `/pets/[petId]`                   |
| 対象ユーザー | 未ログインを含む一般公開          |
| レイアウト   | `(public)/layout` + Public Header |

### 公開条件・404

表示対象は **すべて** 満たす Pet のみ:

- `pets.status = published`
- `pets.deleted_at IS NULL`
- `breeders.review_status = approved`
- `breeders.membership_status = active`
- `breeders.deleted_at IS NULL`

以下は **404**（`notFound()`。403 は使わない）:

- 非公開 Pet、draft、under_review
- 停止・非承認ブリーダーに紐づく Pet
- 存在しない UUID、不正 UUID

### 犬猫表示項目

| 表示する                                                                                                                           | 表示しない                                                                                                               |
| ---------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------ |
| `public_display_name`, `species`, `breed`, `sex`, `birthday`/月齢, `color`, `temperament`, `description`, `price`, `price_comment` | `management_name`, `breeder_id`, `status`, `ai_description`, `ai_generated_at`, 監査カラム, `deleted_at`, その他内部項目 |

### 写真

- private バケット維持、Signed URL 表示
- 複数枚、`is_main` 優先 → `display_order` 順
- 0 枚はプレースホルダー
- `storage_path` は HTML に露出しない
- スマートフォン優先ギャラリー（スワイプ + サムネイル + キーボード対応）

### 「この子について」

- `temperament` / `description` を表示
- NULL または空文字の項目は非表示
- 両方空ならセクション全体非表示
- **`ai_description` は絶対非表示**

### ブリーダー情報

| 表示する                                                                                                                       | 表示しない                                                                                                        |
| ------------------------------------------------------------------------------------------------------------------------------ | ----------------------------------------------------------------------------------------------------------------- |
| `business_name`, `prefecture`, `city`, `profile_text`, `breeding_policy`, `health_policy`, `breeding_environment`（第1期全文） | `phone`, `representative_name`, 詳細住所, `public_email`, `website_url`, 本人確認, Stripe, 審査状態, `user_id` 等 |

### 画面構成

1. Public Header
2. 「犬猫一覧へ戻る」→ `/pets`
3. 写真ギャラリー
4. 公開表示名・基本属性・毛色・価格・価格補足
5. 「この子について」
6. 「ブリーダーについて」

### ブランド方針

- EC 商品詳細のような見せ方にしない
- 価格を主役にせず、写真・性格・紹介・ブリーダーの考え方を優先
- 「出会ったその日から、命は家族になる。」に沿う情報設計

### レスポンシブ・アクセシビリティ

- スマホ: 1 カラム（写真 → 基本 → この子 → ブリーダー）
- PC: 上部 2 カラム + 長文 `max-w-prose`
- 見出し階層、写真 alt、キーボード操作、色だけに依存しない UI、長文可読性
