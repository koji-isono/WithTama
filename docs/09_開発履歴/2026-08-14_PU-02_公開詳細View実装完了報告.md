## 4. 公開条件（PU-01 と完全一致）

### Pet（`published_pet_detail_public`）

| #   | 条件                                    |
| --- | --------------------------------------- |
| 1   | `pets.status = 'published'`             |
| 2   | `pets.deleted_at IS NULL`               |
| 3   | `breeders.deleted_at IS NULL`           |
| 4   | `breeders.review_status = 'approved'`   |
| 5   | `breeders.membership_status = 'active'` |

`public.is_publicly_listable_pet(uuid)` の EXISTS 条件と **同一**（関数本体は変更していない）。

### Breeder（`breeder_public_detail_profiles`）

| #   | 条件                                    |
| --- | --------------------------------------- |
| 1   | `breeders.deleted_at IS NULL`           |
| 2   | `breeders.review_status = 'approved'`   |
| 3   | `breeders.membership_status = 'active'` |

### 検証項目（15 件 + 補助）

1. anon が `published_pet_detail_public` を SELECT できる
2. 公開条件を満たす published Pet が取得できる
3. draft Pet が取得できない

6. 非 approved breeder の Pet が取得できない（env 設定時）
7. deleted Pet が取得できない（`SEC_TEST_PUBLIC_DELETED_PET_ID` 設定時）
8. `management_name` が View に存在しない

10. `status` が View に存在しない
11. anon が `breeder_public_detail_profiles` を SELECT できる

13. `representative_name` が View に存在しない
14. `address_line` が View に存在しない
