## profile_completed 条件

以下 5 必須項目が **すべて有効な値** で保存成功した場合のみ `profile_completed = true`:

- `full_name`
- `display_name`
- `phone`
- `prefecture`
- `city`

- 任意項目は完了条件に含めない
- 保存失敗時は `true` にしない
- 完了済みユーザーも必須項目を空にできない
- UI チェックボックス等でユーザー操作させない

| 状態       | 動作       |
| ---------- | ---------- |
| 未ログイン | `/login`   |
| buyer      | 利用可     |
| breeder    | `/breeder` |

- 更新対象 buyer は Server 側で `auth.uid()` から特定
- **Service Role 不使用**

## 個人情報方針

- `buyers` は **本人 READ/UPDATE のみ**（既存 RLS 維持）
- ブリーダー SELECT RLS / public View / 電話番号一般公開は **行わない**
- メールは Auth 正本、`buyers` へコピーしない
- ブリーダーへの開示方式は問い合わせ設計時に Decision 化
