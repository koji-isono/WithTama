## 1. 実装概要

`/buyer/dashboard` のプレースホルダーを BY-02 ダッシュボード UI に置き換えた。

- Supabase Auth のログインユーザーを `requireBuyer()`（buyer layout）で検証
- `loadBuyerDashboardPageData()` で本人の `public.buyers` 行を取得（RLS 準拠）
- プロフィール未登録（行なし or `profile_completed = false`）→ `/buyer/profile` へリダイレクト
- 登録済みの場合、挨拶文と 5 つのメニューカードを表示
- 既存 BY-01 プロフィール画面・データ層は変更せず再利用

## 5. 認証・RLS の対応内容

| 条件                         | 動作                         |
| ---------------------------- | ---------------------------- |
| 未ログイン                   | `requireBuyer()` → `/login`  |
| admin                        | `/admin` へリダイレクト      |
| breeder                      | `/breeder` へリダイレクト    |
| buyer + プロフィール未登録   | `redirect("/buyer/profile")` |
| buyer + プロフィール登録済み | ダッシュボード表示           |

- プロフィール取得: `getBuyerProfileByUserId(user.id)` — 本人 `user_id` のみ
- RLS: 既存 `buyers` ポリシーをそのまま利用（Migration / ポリシー変更なし）
- Service Role: 不使用。クライアントへ `SUPABASE_SERVICE_ROLE_KEY` 等を公開していない
