## DB 利用

- 既存 `public.favorites` テーブルを使用（新規 migration なし）
- `buyer_id` は Server 側で `auth.uid()` → `buyers.id` から解決
- 一覧表示は `published_pets_public` View 経由（非公開 Pet を除外）

---

## RLS 利用

- 既存ポリシー `favorites_select_own` / `favorites_insert_own` / `favorites_delete_own` をそのまま利用
- RLS 無効化・service_role 不使用

---

## 認証方式

- BY-03: 既存 `requireBuyer()`（buyer layout）
- お気に入り操作: Server Action 内で buyer ロール + `buyers` 行確認
- 未ログイン PU-02: `/login?next=/pets/{petId}`
