## 実装内容

- URL: `/breeder/visits/[visitId]`
- `loadBreederVisitDetailPage()` — breeder 本人 visit + inquiry + pet + buyer 表示名（RPC）
- **requested** → `scheduleVisitAction` → `schedule_visit` RPC（「見学日時を確定する」）
- **scheduled** → `completeVisitAction` → `complete_visit` RPC（現物確認・対面説明 checkbox + result select）
- **requested / scheduled** → `cancelVisitActionForBreeder` → `cancel_visit` RPC
- **completed / canceled** → 閲覧のみ
- 導線: BR-14 一覧へ戻る / BR-12 問い合わせ詳細
