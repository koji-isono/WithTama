# BY-06 / PU-02 見学導線 実装完了報告

## 実装内容

共通ロジック `resolveInquiryVisitNavigation()` を `src/features/visits/constants.ts` に追加し、PU-02 / BY-06 で再利用。

- **visit あり** → `getBuyerVisitDetailPath`（BY-09）— status に関係なく優先
- **visit なし + open/replied** → `getBuyerVisitNewPath`（BY-07）
- **それ以外** → ボタン非表示

## PU-02 分岐

| 条件                                      | 遷移                                  |
| ----------------------------------------- | ------------------------------------- |
| 未ログイン                                | `/login?next=/pets/[petId]`           |
| buyer 以外                                | ボタン非表示                          |
| profile 未完了                            | `/buyer/profile`                      |
| 有効 inquiry なし                         | BY-04 `getBuyerInquiryNewPath(petId)` |
| inquiry あり / visit なし / open・replied | BY-07                                 |
| visit あり                                | BY-09                                 |

`loadVisitStartUiState(petId)` + `VisitStartButton`（outline）を既存 CTA 横に配置。

## BY-06 分岐

`loadInquiryDetailPage` で `getVisitIdByInquiryId` を照会し、`visitNavigation` を page data に付与。

| 条件                                                                 | ボタン                    |
| -------------------------------------------------------------------- | ------------------------- |
| visit なし / open・replied                                           | 「見学を希望する」→ BY-07 |
| visit あり                                                           | 「見学詳細を見る」→ BY-09 |
| visit_requested / visit_scheduled / completed / closed（visit なし） | 非表示                    |
