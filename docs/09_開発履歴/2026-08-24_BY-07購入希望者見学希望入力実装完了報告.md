## 1. 目的

購入希望者が **本人の問い合わせ（inquiry）** に紐づく見学希望を、希望日時（最大3候補）とメッセージとともにブリーダーへ送信できる画面（BY-07）を実装する。

既存の `request_visit` SECURITY DEFINER RPC を利用し、`visits` への直接 INSERT や Service Role は使用しない。

## 3. 実装内容

### 3.1 機能概要

- 購入希望者（`profile_completed = true`）が inquiryId 指定で BY-07 を表示
- 犬猫サマリー（写真・名前・属性・ブリーダー名・問い合わせ状態）を確認
- 第一〜第三希望（`datetime-local`）+ メッセージ（必須）を入力
- Server Action 経由で `request_visit` RPC 呼び出し
- 成功時 BY-09 パスへ redirect + 成功メッセージ表示
- visit 既存時は loader で BY-09 へ redirect（二重申請防止）
- inquiry が `open` / `replied` 以外はエラー表示

### 3.2 アーキテクチャ

`src/features/visits/` を新設。`inquiries` feature と同型の責務分離:

| 層 | ファイル | 責務 |
| -- | -------- | ---- |
| constants | `constants.ts` | パス・メッセージ・eligible status |
| datetime | `datetime.ts` | datetime-local → ISO UTC 変換 |
| validation | `validation.ts` | クライアント/サーバー共通バリデーション |
| errors | `errors.ts` | RPC エラー → 日本語メッセージ |
| repository | `repository.ts` | `request_visit` RPC・visit 存在確認 |
| service | `service.ts` | `requestVisitAction`（buyer 認可・RPC 実行） |
| loaders | `loaders.ts` | `loadVisitRequestPage`（ページデータ・redirect） |
| UI | `components/visit-request-form.tsx` 等 | フォーム・サマリーカード |

## 7. request_visit RPC との接続

```typescript
await supabase.rpc("request_visit", {
  p_inquiry_id: inquiryId,
  p_requested_at: requestedAtIso,           // datetime-local → ISO UTC
  p_requested_at_second: requestedAtSecondIso ?? undefined,
  p_requested_at_third: requestedAtThirdIso ?? undefined,
  p_message: normalizedMessage,
});
```

- **直接 `visits` INSERT なし**
- RPC 成功後の `inquiries.status → visit_requested` / `inquiry_messages` INSERT は RPC 側に一任
- UI/Service 側で同内容の DB 更新を重複実装していない

## 8. バリデーション

| 項目 | ルール |
| ---- | ------ |
| 第一希望 | 必須・未来日時 |
| 第二・第三 | 任意・入力時は前候補より後 |
| メッセージ | 必須・2000文字以内（BY-04 同型） |
| inquiryId | UUID 形式 |
| inquiry status | `open` / `replied` のみ送信可 |
| visit 重複 | loader + service + RPC UNIQUE で防止 |

### タイムゾーン

`datetime-local` はブラウザのローカルタイムゾーン（日本国内利用想定では JST）で解釈し、`datetimeLocalToIso()` で UTC ISO 8601 に変換して RPC へ渡す。

## 9. エラー処理

| RPC/条件 | ユーザー向けメッセージ |
| -------- | ---------------------- |
| 過去日時 | 未来の日時を選択してください。 |
| 権限エラー / 他人 inquiry | この問い合わせでは見学を申し込めません。 |
| visit 既存 / 二重申請 | すでに見学希望が登録されています。（BY-09 へ redirect） |
| inquiry 不可 status | この問い合わせでは見学希望を送れません。 |
| 通信・想定外 | 見学希望を送信できませんでした。時間をおいてもう一度お試しください。 |

Supabase の生エラーメッセージは `mapRequestVisitRpcError()` で変換。開発時のみ `console.error` に詳細出力。
