## 8. データ取得方法

1. `getCurrentBuyer()` — 未ログイン時 `/login?next=...`
2. `getBuyerProfileByUserId` — buyer プロフィール確認
3. UUID 形式チェック（不正 → 404）
4. `getVisitByIdForBuyer(visitId, buyerId)` — **buyer_id 一致 + deleted_at IS NULL**（RLS 併用）
5. `getInquiryByIdForBuyer` — inquiry 所有確認
6. `loadInquiryPetSummaryForDetail` — 犬猫情報
7. `findVisitRequestMessage` — 見学希望時メッセージ

他人の visit / 不存在 → **同一く 404**（存在推測を防ぐ）

## 11. cancel_visit との接続

```typescript
await supabase.rpc("cancel_visit", {
  p_visit_id: visitId,
  p_cancellation_reason: reason || undefined,
});
```

- **visits テーブル直接 UPDATE なし**
- RPC 成功後 `router.refresh()` で画面再取得

## 12. キャンセル可能条件

| 条件          | 内容                                              |
| ------------- | ------------------------------------------------- |
| UI 表示       | `visits.status` が `requested` または `scheduled` |
| Server Action | 同上 + buyer 本人確認                             |
| RPC           | `cancel_visit` 内で再検証                         |

`completed` / `canceled` は閲覧のみ。

## 14. エラー処理

| ケース                | メッセージ                                                           |
