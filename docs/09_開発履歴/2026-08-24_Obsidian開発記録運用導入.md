# Obsidian 開発記録運用 導入報告

## 目的

WithTama プロジェクトルートを Obsidian Vault として活用し、Cursor での開発と Obsidian での設計・履歴俯瞰を **同一 Markdown** で行えるようにする。Obsidian 専用コピーを作らず、既存 `docs/` 構成と Git 管理を維持する。

## 運用ルール（要約）

- 開発完了報告 → `docs/09_開発履歴/`
- 命名: `YYYY-MM-DD_画面IDまたは機能名_内容.md`（既存ファイルはリネームしない）
- 新規報告に YAML Frontmatter を付与（`type: development-log` 等）
- Obsidian リンク: `[[docs/...]]` 形式（Vault ルート基準）
- 必須セクション 11 項目（目的〜関連ノート）

詳細: [[docs/10_運用手順/Obsidian運用ルール]]

## Git 管理方針

- 本導入は **ドキュメントのみ**（アプリコード・DB・migration 変更なし）
- `git commit` / `push` は本タスクでは未実施
- 既存開発履歴 MD の一括 Frontmatter 付与は **行わない**

## 今後の開発記録方法

1. 機能実装・設計変更・調査完了時に `docs/09_開発履歴/` へ MD を追加
2. [[docs/10_運用手順/Obsidian運用ルール]] の Frontmatter・必須セクションに従う
3. [[docs/00_WithTamaホーム]] の「最近の開発履歴」は必要に応じて手動または次回作業時に更新
