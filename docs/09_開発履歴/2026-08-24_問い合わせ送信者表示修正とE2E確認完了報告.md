# 問い合わせ機能 送信者表示修正・E2E 確認 完了報告

**日付:** 2026-08-24  
**対象:** BR-12 / BY-06 メッセージ送信者ラベル、問い合わせ E2E 確認

---

## 1. 結論

BR-12 詳細画面で購入希望者メッセージの送信者が誤って「あなた」と表示されていた問題を修正した。BY-06 の表示仕様（自分＝「あなた」、ブリーダー＝「ブリーダー」）は維持している。

---

## 2. 問題と原因

| 画面                  | 期待                                                 | 修正前                 |
| --------------------- | ---------------------------------------------------- | ---------------------- |
| BY-06（buyer 視点）   | buyer メッセージ →「あなた」                         | 正しい                 |
| BR-12（breeder 視点） | buyer メッセージ → display_name または「購入希望者」 | **「あなた」**（誤り） |

**原因:** `getInquiryMessageSenderLabel()` が `sender_type === "buyer"` のとき常に「あなた」を返しており、閲覧者（viewer）を考慮していなかった。

---

## 3. 修正内容

### 3.1 `getInquiryMessageSenderLabel()` を viewer 対応に拡張

**ファイル:** `src/features/inquiries/format.ts`

| viewerRole | sender_type | 表示ラベル                                            |
| ---------- | ----------- | ----------------------------------------------------- |
| `buyer`    | `buyer`     | あなた                                                |
| `buyer`    | `breeder`   | ブリーダー                                            |
| `breeder`  | `buyer`     | RPC で取得した `display_name`、なければ「購入希望者」 |
| `breeder`  | `breeder`   | あなた                                                |

### 3.2 Loader 更新

| Loader                                  | 変更                                                 |
| --------------------------------------- | ---------------------------------------------------- |
| `loadInquiryDetailPage`（BY-06）        | `{ viewerRole: "buyer" }` を明示                     |
| `loadBreederInquiryDetailPage`（BR-12） | `{ viewerRole: "breeder", buyerDisplayName }` を渡す |

`buyerDisplayName` は既存どおり `get_inquiry_buyer_display_name` RPC から取得。`buyers` テーブル直接 SELECT・Service Role は使用していない。

---

- `buyers` への breeder SELECT 追加なし
- Service Role クライアント不使用

## 8. 残課題

1. **フル E2E（B 系）** — `.env.local` に `SEC_TEST_BUYER_EMAIL` / `SEC_TEST_BUYER_PASSWORD` を設定し `npm run test:inquiry-e2e` を再実行すると、新規問い合わせ〜返信〜`replied` 更新まで自動検証可能
2. **実機 UI 確認** — dev サーバー上で BR-12 詳細を開き、送信者ラベル表示を目視確認（E2E F5 でロジックは検証済み）
3. **RPC migration** — `20260821153000` 未適用環境では display_name がフォールバック「購入希望者」になる（今回の DB では RPC 動作確認済み）
