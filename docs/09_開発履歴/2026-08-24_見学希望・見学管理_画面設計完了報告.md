## 4. 決定事項

### 4.1 画面 ID・URL

| 画面 ID | 画面名                               | URL                                       |
| ------- | ------------------------------------ | ----------------------------------------- |
| BY-07   | 見学希望入力                         | `/buyer/visits/new?inquiryId={inquiryId}` |
| BY-08   | 見学予定一覧                         | `/buyer/visits`                           |
| BY-09   | 見学詳細                             | `/buyer/visits/[visitId]`                 |
| BR-14   | 見学管理一覧                         | `/breeder/visits`                         |
| BR-15   | 見学詳細                             | `/breeder/visits/[visitId]`               |
| BR-11   | **犬猫編集のみ**（見学 ID から分離） | `/breeder/pets/[petId]/edit`              |

### 4.2 見学フロー

- 見学希望には **有効 inquiry 必須**。1 inquiry 1 visit（UNIQUE）
- PU-02「見学を希望する」: inquiry なし → BY-04 / visit なし → BY-07 / visit あり → BY-09
- BY-06 に「見学を希望する」導線（visit 未作成・`open` / `replied` 時）
- 第一希望日時 **必須**、第二・第三 **任意**
- 見学希望メッセージ → **`inquiry_messages`**

### 4.3 ステータス

**visits.status（既存 4 値のみ）:** `requested` → `scheduled` → `completed` / `canceled`

**inquiries 連動（Decision No.119）:**

| 操作           | inquiries.status              |
| -------------- | ----------------------------- |
| 見学希望       | `visit_requested`             |
| 日時確定       | `visit_scheduled`             |
| 見学完了       | `completed`                   |
| 見学キャンセル | `replied`（メッセージ継続可） |

### 4.4 見学実施記録

- `animal_confirmed`（現物確認）、`explanation_completed`（対面説明）
- 完了時 `result` 設定。`contracted` = **サイト外** の結果記録（Decision No.122）

### 4.5 セキュリティ・DB

- RLS 弱体化 **なし**、Service Role **不使用**
- buyer / breeder の更新項目 **分離**（Decision No.123）
- **`visits` テーブル構造は変更しない**
- 複数テーブル更新は **SECURITY DEFINER RPC**（Decision No.121）。`auth.uid()` 確認、EXECUTE 最小権限

### 4.6 第1期スコープ外（再確認）

リアルタイム予約カレンダー、空き時間管理、犬猫代金決済、サイト内売買契約、詳細住所自動開示、電子署名

| 118 | inquiry 必須・PU-02 / BY-06 導線                 |
