## 修正内容

### 改善1：BR-15 見学結果 select のレイアウト

- 見学結果 select と下部アクション（成約の説明・完了ボタン）を **区切り線で分離**
- select の `SelectContent` に `collisionPadding` と高めの `z-index` を指定
- 成約の補足説明を完了ボタン直上の独立ブロックに配置
- 既存 Radix Select / デザインシステムを維持

### 改善2：確定日時前の見学完了拒否（Decision No.124）

| 層               | 内容                                                                                                     |
| ---------------- | -------------------------------------------------------------------------------------------------------- |
| RPC              | `complete_visit` で `scheduled_at IS NULL OR scheduled_at > now()` の場合は例外                          |
| エラー文言（UI） | 「確定した見学日時より前に見学を完了することはできません。」                                             |
| フロント         | `canCompleteNow` が false の間は完了ボタン disabled + 「見学完了は確定した見学日時以降に記録できます。」 |
| 維持             | 現物確認・対面説明の両方 true 必須、成約の説明文                                                         |
