## 5. 表示項目

| 項目                             | データソース                                     |
| -------------------------------- | ------------------------------------------------ |
| 屋号・事業所名（空時は代表者名） | `breeders.business_name` / `representative_name` |
| 代表者名                         | `breeders.representative_name`                   |
| 都道府県                         | `breeders.prefecture`                            |
| 審査状態                         | `breeders.review_status`（Badge）                |
| 本人確認状態                     | `breeders.identity_verification_status`          |
| 登録証確認状態                   | `breeders.business_verification_status`          |
| 登録有効期限                     | `breeders.registration_expires_at`               |
| 申請日時                         | `breeder_review_logs` 最新 `submitted`           |
| 詳細ボタン                       | AD-02 へリンク                                   |

**設計書との差異（意図的準拠）:** AD-01 設計書に登録番号の一覧表示はないため、第一種動物取扱業登録番号は今回表示していない。

## 6. status 表示

| DB 値                   | 日本語ラベル                                |
| ----------------------- | ------------------------------------------- |
| `submitted`             | 申請済み                                    |
| `under_review`          | 審査中                                      |
| `resubmission_required` | 差戻し                                      |
| `approved`              | 承認済み（ラベル定義のみ。第1期一覧対象外） |
| `rejected`              | 却下（ラベル定義のみ。第1期一覧対象外）     |

## 8. 取得条件・並び順

- `review_status IN ('submitted', 'under_review', 'resubmission_required')`
- `deleted_at IS NULL`
- 申請日時（`breeder_review_logs` 最新 `submitted`）昇順

第1期では `approved` / `rejected` の履歴一覧は対象外（設計書どおり）。

---

## 9. 期限切れ表示

- 期限切れ: 「期限切れ」Badge（destructive）
- 30 日以内: 「30日以内」Badge（amber）
- 承認可否の最終判断は RPC 側（画面は警告表示のみ）
