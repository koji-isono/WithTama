## 3. 承認

- ボタン: 「承認する」（primary）
- RPC: `approve_breeder_review(p_breeder_id)`
- 確認ダイアログ: 「このブリーダー申請を承認しますか？」＋月額課金開始前は利用開始状態にならない旨
- 成功時:
  - `review_status = approved`
  - `identity_verification_status = verified`
  - `business_verification_status = verified`
  - `approved_at = now()`
  - `breeder_review_logs.action = approved`
- **`membership_status` は変更しない**（Decision No.129 / No.130）

---

## 4. 差戻し

- ボタン: 「差戻す」（outline）
- RPC: `return_breeder_review(p_breeder_id, p_comment)`
- 理由必須（空文字・空白のみ不可、UI + Server Action で検証）
- 成功時:
  - `review_status = resubmission_required`
  - verification ステータスは変更しない
  - `breeder_review_logs.action = returned` + comment

---

## 5. 却下

- ボタン: 「却下する」（destructive）
- RPC: `reject_breeder_review(p_breeder_id, p_comment)`
- 理由必須（差戻しと別 textarea、確認ダイアログも分離）
- 成功時:
  - `review_status = rejected`
  - verification ステータスは変更しない
  - `breeder_review_logs.action = rejected` + comment
- 第1期では rejected からの再申請不可

---

## 6. 表示条件

`canPerformBreederReviewActions()` — **`review_status = under_review` のみ**

以下では操作 UI 非表示:

- submitted / resubmission_required / approved / rejected / draft

---

## 7. Server Action

| Action                       | 検証                     | RPC                    |
| ---------------------------- | ------------------------ | ---------------------- |
| `approveBreederReviewAction` | requireAdmin + breederId | approve_breeder_review |
| `returnBreederReviewAction`  | + 差戻し理由             | return_breeder_review  |
| `rejectBreederReviewAction`  | + 却下理由               | reject_breeder_review  |

共通:

- Service Role 不使用
- 成功後 `revalidatePath` で AD-01 / AD-02 再検証
- Postgres 内部エラーは安全な日本語メッセージに変換

---

## 8. status 遷移

```
under_review
  → approve_breeder_review  → approved
  → return_breeder_review   → resubmission_required
  → reject_breeder_review   → rejected
```

状態遷移の正本は RPC 側。

---

## 9. membership_status

承認操作でも **`membership_status` は変更しない**。

承認後も `review_status = approved` かつ `membership_status = pending` が正常。

`membership_status = active` は Stripe 工程で扱う（未実装）。

---

## 10. 審査履歴

RPC 成功時に `breeder_review_logs` へ追記:

- `approved` / `returned` / `rejected`
- 差戻し・却下時は comment を保存・表示

---

## 11. 権限制御

- 各 Server Action 内 `requireAdmin()`
- admin レイアウト `requireAdmin()`（既存）
- 非 admin は Action 拒否

## 12. エラー処理

| 却下   | 却下できませんでした。状態を確認してもう一度お試しください。   |
