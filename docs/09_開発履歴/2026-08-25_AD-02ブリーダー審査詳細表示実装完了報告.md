## 4. 表示項目

| セクション       | 内容                                                                                            |
| ---------------- | ----------------------------------------------------------------------------------------------- |
| 基本情報         | 屋号、代表者名、電話、公開メール、Webサイト、審査/確認状態、利用状態、承認日時、Stripe 課金状態 |
| 所在地           | 郵便番号、都道府県、市区町村、番地                                                              |
| 第一種動物取扱業 | 登録種別、番号、自治体、有効期限（警告付き）                                                    |
| プロフィール     | 紹介、繁殖/健康方針、飼育環境                                                                   |
| 本人確認書類     | 確認状態 + プレビュー                                                                           |
| 登録証           | 確認状態 + プレビュー                                                                           |
| 審査履歴         | action / comment / created_at                                                                   |

---

## 5. 個人情報

admin 専用のため審査に必要な個人情報（電話、住所等）を表示。`user_id`、Stripe 内部 ID、Storage path は非表示。

---

## 6. Signed URL

- `requireAdmin()` 後、Server 側で admin JWT + `createSignedUrl`
- バケット: `breeder-documents`（private）
- TTL: **300 秒**（`BREEDER_DOCUMENT_SIGNED_URL_EXPIRES_SECONDS`）
- Service Role 不使用

---

## 7. Storage / 書類プレビュー

- 画像（jpg/jpeg/png）: `<img>` プレビュー
- PDF: `<iframe>` プレビュー
- 「新しいタブで開く」リンク（Signed URL のみ、永久リンクなし）
- path なし → 「書類が未提出です」
- Signed URL 失敗 → 「書類を表示できませんでした」（画面全体は落とさない）

---

## 8. 登録期限

- 期限切れ / 30 日以内 / 未設定を Badge 表示
- 承認可否の最終判定は `approve_breeder_review` RPC 側

---

## 9. 審査履歴

`breeder_review_logs` を `created_at` 昇順表示。`actor_user_id` は UUID 表示せず省略。

| action         | ラベル   |
| -------------- | -------- |
| submitted      | 申請     |
| review_started | 審査開始 |
| approved       | 承認     |
| returned       | 差戻し   |
| rejected       | 却下     |

---

## 10. status 表示

AD-01 と共通の `BREEDER_REVIEW_STATUS_LABELS` / `formatAdminVerificationStatus` / `formatAdminMembershipStatus` を使用。

---

## 11. 対象 breeder

- `deleted_at IS NULL`
- `review_status IN (submitted, under_review, resubmission_required, approved, rejected)`
- `draft` は 404
