## 1. 目的

管理者がブリーダー申請の審査を明示的に開始し、`review_status` を `under_review` に遷移させる。

## 3. 表示条件

AD-02 設計書（Decision No.126）に従い、以下のとき「審査を開始する」を表示:

- `review_status = submitted`
- `review_status = resubmission_required`

それ以外（`under_review` / `approved` / `rejected`）では非表示。

---

## 4. Server Action

`startBreederReviewAction(breederId)`:

- `requireAdmin()`
- `validateBreederIdForAdminReview`
- `start_breeder_review` RPC 呼び出し
- `revalidatePath` で AD-01 / AD-02 を再検証
- Service Role 不使用

---

## 5. RPC

`start_breeder_review(p_breeder_id)` — **変更なし**（既存 Migration 済み）

---

## 6. status 遷移

```
submitted | resubmission_required
  → start_breeder_review
  → under_review
```

---

## 7. review log

RPC 成功時に `breeder_review_logs` へ `action = review_started` を追記。

---

## 8. 権限制御

- Server Action 内 `requireAdmin()`
- admin レイアウト `requireAdmin()`（既存）
- エラー詳細は画面に露出しない
