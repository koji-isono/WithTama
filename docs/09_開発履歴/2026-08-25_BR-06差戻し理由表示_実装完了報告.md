## 認証方式

`loadBreederDashboardPageData()` 内で `requireBreeder()` を必ず呼び出し。

| 条件       | 動作                     |
| ---------- | ------------------------ |
| 非ログイン | `/login` へリダイレクト  |
| buyer      | `/buyer` へリダイレクト  |
| admin      | `/admin` へリダイレクト  |
| breeder    | ダッシュボードデータ取得 |

buyer dashboard / breeder 問い合わせと同パターン。

---

## review_status 取得方式

- Server client（`@/lib/supabase/server`）使用
- `getBreederReviewSummaryByUserId(user.id)` で `breeders.review_status` を取得
- Service Role **不使用**

---

## returned comment 取得方式

`review_status === "resubmission_required"` の場合のみ:

```typescript
.from("breeder_review_logs")
.select("comment")
.eq("action", "returned")
.order("created_at", { ascending: false })
.limit(1)
.maybeSingle()
```

- RLS `breeder_review_logs_select_breeder_own` により本人のみ
- 他 status では comment を取得・表示しない
- 取得失敗時は `loadLatestReturnedCommentSafely()` で null にフォールバック

## UI 仕様

| 要素       | 内容                                                     |
| ---------- | -------------------------------------------------------- |
| 表示条件   | `review_status === "resubmission_required"` のみ         |
| 見出し     | 申請内容に修正が必要です                                 |
| 差戻し理由 | 最新 returned comment                                    |
| 説明       | 内容を修正し、再提出してください。                       |
| CTA        | 申請内容を修正する                                       |
| 遷移先     | `/breeder/profile/basic`（`BREEDER_PROFILE_BASIC_PATH`） |
| スタイル   | amber 系 Alert（過度な赤警告を避ける）                   |

---

## フォールバック

comment 取得エラー / null / 空文字時:

```
申請内容に修正が必要です。詳細は管理者へお問い合わせください。
```

- Supabase `error.message` 等を UI に表示しない
- comment 本文を `console.log` 等へ出力しない

---

## セキュリティ

| 要件                  | 対応                      |
| --------------------- | ------------------------- |
| 他 breeder の comment | RLS で不可                |
