# BR-09 差戻し→再提出→再審査 Decision 確定報告

## 確定 Decision

| No.     | 概要                                                                                |
| ------- | ----------------------------------------------------------------------------------- |
| **135** | 差戻し理由は BR-06 ダッシュボードに表示。専用申請状況画面は第1期で作らない          |
| **136** | プロフィール編集は `draft` / `resubmission_required` のみ。Server Action でも検証   |
| **137** | 再提出 RPC `resubmit_breeder_application` + 初回・再提出の `submitted` log 原子記録 |
| **138** | 第1期 BR-09 ではメール通知なし（サイト内表示のみ）                                  |

---

## 状態遷移（正本）

```
draft → 初回提出 → submitted → 審査開始 → under_review
  → 差戻し → resubmission_required → 修正 → 再提出 → submitted
  → 審査開始 → under_review → 承認 / 再差戻し / 却下
```

再提出から **直接 `under_review` にはしない**（Decision No.126）。

## 再提出 RPC 方針

| 項目   | 内容                                                       |
| ------ | ---------------------------------------------------------- |
| 名称   | `resubmit_breeder_application`                             |
| 実行者 | ログイン中ブリーダー本人                                   |
| 前提   | `review_status = resubmission_required`                    |
| 処理   | `submitted` へ + `breeder_review_logs(action = submitted)` |
| 除外   | `under_review` へ変更しない、`membership_status` 不変      |

---

## 初回 submitted log 方針

- 現状 `completeBreederProfile` は log 未 INSERT（設計不整合）
- 初回 `draft` → `submitted` でも `submitted` log を原子的に記録
- 実装方式（RPC 新設 / 改修 / 共通化）は **実装工程で決定**

---

## メール方針

- 第1期: **サイト内のみ**（Decision No.138）
- Resend 差戻し・再提出通知メール: **別工程**

---

## セキュリティ方針

- 本人のみ: 差戻し理由閲覧・プロフィール修正・再提出
- 他ブリーダー / buyer / 非ログイン: 不可
- 管理者審査 RPC: breeder から実行不可
- private 書類非公開、Signed URL をログに保存しない
