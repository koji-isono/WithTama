# BR-09 FAIL 12 テスト修正完了報告

## 作業目的

`test:breeder-application-submit-rpcs` の唯一の FAIL（FAIL 12）を、調査報告に基づき **テストのみ** 修正する。

---

## FAIL 12 の原因

| 項目         | 内容                                                                                                                                                                     |
| ------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| 現象         | `FAIL 12 unauthenticated resubmit rejected`                                                                                                                              |
| 分類         | B + C + D（主因: テスト判定ミス）                                                                                                                                        |
| 実際のエラー | `42501` / `permission denied for function resubmit_breeder_application`                                                                                                  |
| 原因         | `anon` に EXECUTE 権限がないため、関数内 `authentication required` に到達せず Postgres 権限エラーで拒否。テストが `"authentication required"` のみを PASS 条件にしていた |

---

## 修正内容

**対象:** `scripts/test-breeder-application-submit-rpcs.mts`

| 変更    | 内容                                                                                                         |
| ------- | ------------------------------------------------------------------------------------------------------------ |
| FAIL 12 | `error != null` で拒否成功と判定（`test-visit-rpcs.mts` と同考え方）                                         |
| 追加    | `12 unauthenticated initial submit rejected` — `submit_breeder_application()` も同基準で未ログイン拒否を確認 |

**セキュリティ設計は変更していない:**

- Migration / RPC / GRANT / REVOKE — **変更なし**
- `anon` への EXECUTE 付与 — **なし**
- src / Supabase DB — **変更なし**
