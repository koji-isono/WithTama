## 原因

### Migration の GRANT / REVOKE

`20260825130000_create_breeder_application_submit_rpcs.sql` より:

```sql
REVOKE ALL ON FUNCTION public.submit_breeder_application() FROM PUBLIC;
REVOKE ALL ON FUNCTION public.submit_breeder_application() FROM anon;
GRANT EXECUTE ON FUNCTION public.submit_breeder_application() TO authenticated;

REVOKE ALL ON FUNCTION public.resubmit_breeder_application() FROM PUBLIC;
REVOKE ALL ON FUNCTION public.resubmit_breeder_application() FROM anon;
GRANT EXECUTE ON FUNCTION public.resubmit_breeder_application() TO authenticated;
```

### 動作の流れ

1. テストの `anonClient` は publishable key のみでセッションなし（`persistSession: false`）
2. PostgREST は Postgres ロール **`anon`** として RPC を呼び出す
3. `anon` に EXECUTE 権限がないため、**関数本体が実行されない**
4. 関数内の `RAISE EXCEPTION 'authentication required'`（`auth.uid() IS NULL` 分岐）には **到達しない**
5. Postgres が `42501 permission denied for function ...` を返す

### テスト側

`scripts/test-breeder-application-submit-rpcs.mts` FAIL 12:

```typescript
anonResubmitError != null && includes(rpcMessage(anonResubmitError), "authentication required");
```

エラーは返っているが、メッセージが `"authentication required"` ではないため FAIL。

## 現在の EXECUTE 権限

| ロール        | `submit_breeder_application()`    | `resubmit_breeder_application()`  |
| ------------- | --------------------------------- | --------------------------------- |
| anon          | ❌ EXECUTE 不可                   | ❌ EXECUTE 不可                   |
| authenticated | ✅ EXECUTE 可（関数内で本人検証） | ✅ EXECUTE 可（関数内で本人検証） |
| public        | ❌ REVOKE ALL 済み                | ❌ REVOKE ALL 済み                |

既存 RPC（`submit_pet_for_review` / `request_visit` / `start_breeder_review` 等）と **同一パターン**。

## セキュリティ上の評価

**問題なし。現状の Migration 設計は正しく、より強い。**

| 方式                                                       | 評価                            |
| ---------------------------------------------------------- | ------------------------------- |
| anon に EXECUTE を付け、関数内で `authentication required` | 弱い（到達可能）                |

セキュリティ要件:

| 要件                               | 満たすか                        |
| ---------------------------------- | ------------------------------- |
| authenticated breeder 本人のみ成功 | ✅（別テストで PASS）           |
| 非ログインは必ず拒否               | ✅（`42501 permission denied`） |
| buyer 拒否                         | ✅（PASS）                      |
| admin 拒否                         | ✅（PASS）                      |

既存 `scripts/test-visit-rpcs.mts` は未ログイン拒否を **`anonError != null`（任意のエラー）** で判定しており、今回の DB 設計と整合。
