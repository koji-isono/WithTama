## 1. 根本原因

AD-02 ブリーダー審査テスト後、SEC_TEST ブリーダー（`c975c260-d0b8-40f4-9745-1557c64eb856`）が **`prepare:sec-test-review-breeder` の前提状態**から外れていた。

### 要求される状態遷移（スクリプト調査結果）

| スクリプト                        | 前提                                                   | 実行内容                                                                                                                                       |
| --------------------------------- | ------------------------------------------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------- |
| `prepare:sec-test-breeder-review` | 書類パスあり                                           | admin JWT で `submitted/submitted/submitted`、`approved_at = null` に reset。**`membership_status` は変更しない**                              |
| `prepare:sec-test-review-breeder` | 上記 submitted 状態 + 有効な `registration_expires_at` | admin JWT で `approved/verified/verified` に更新。**`membership_status` は変更しない**                                                         |
| `prepare:sec-test-review-pets`    | breeder が `approved/verified/verified`                | under_review Pet 2 件を準備（今回は不要だった）                                                                                                |
| `prepare:sec-test-public-read`    | breeder `review_status = approved`                     | `membership_status` を `pending → active`（既に active ならスキップ）。`[SEC-TEST] Submit RPC With Photo Pet` の published + main photo を確認 |
| `test:visit-rpcs` 等              | `published_pets_public` に公開ペットが見えること       | なければ inquiry 作成 → `request_visit` RPC で `requested` visit を生成                                                                        |

### 失敗の連鎖

1. SEC_TEST ブリーダーが `submitted/submitted/submitted` でない → `prepare:sec-test-review-breeder` FAIL
2. 公開 READ 前提が満たされない → `published_pets_public` に SEC_TEST ブリーダーのペットが見えない
3. 見学テストが `no published pet found` / `no requested visit` で FAIL

公開ペット `[SEC-TEST] Submit RPC With Photo Pet`（`bb3c9725-5615-44aa-8913-286348203a41`）は DB に残っていたが、**ブリーダー側の公開 READ 前提**が満たされていなかった。
