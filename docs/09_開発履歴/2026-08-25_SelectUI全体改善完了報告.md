# Select UI 全体改善 完了報告

## 目的

BR-15「見学結果」プルダウンで、選択肢表示と補足説明が重なって見づらい問題を、BR-15 個別修正ではなく **WithTama 全体の select UI** として改善する。

すべて `@/components/ui/select`（Radix UI `@radix-ui/react-select`）経由。

## 原因

1. **ドロップダウンは Portal で下方向に展開**するため、select 直下に配置した補足説明が画面上で選択肢と重なって見える
2. 共通 `SelectContent` の z-index・背景・衝突回避が弱く、Windows + Chrome で視認性が低かった
3. 各フォームで trigger の高さ・エラー表示・余白が個別に重複定義されていた

## 採用した改善方法

### 1. 共通 `select.tsx` の強化

- trigger: `h-11`、縦中央揃え、▼アイコン余白、`focus-visible` / `data-[state=open]` リング
- `selectTriggerVariants({ error })` でエラー・disabled 状態を統一
- content: `z-[200]`、`bg-white`、`shadow-lg`、`sideOffset=8`、`collisionPadding=24`
- item: `min-h-10` でタップしやすく

### 2. 新規 `SelectField` ラッパー

- `src/components/ui/select-field.tsx`
- **補足説明（hints）を select の上**に配置（Portal ドロップダウンと重ならない）
- エラーは select の直下のみ

### 3. BR-15

- `SelectField` を採用
- 「成約」説明・「見学完了は確定した見学日時以降…」を **hints（select 上方）** に移動
- 完了ボタンは別セクション（区切り線以下）に分離

### 4. 既存フォーム

- 重複していた `selectTriggerClassName` を削除
- `SelectTrigger error={...}` に統一
- `ProfileFormField` で select のエラー枠線をサポート
