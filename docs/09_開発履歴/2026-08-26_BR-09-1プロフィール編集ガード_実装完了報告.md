# BR-09-1 プロフィール編集ガード 実装完了報告

## 目的

Decision No.136 に従い、BR-09 プロフィール編集を `draft` / `resubmission_required` のみ許可し、それ以外の status では画面・Server Action 双方で編集を禁止する。

---

## 実装概要

| レイヤ            | 内容                                                                       |
| ----------------- | -------------------------------------------------------------------------- |
| `edit-guard.ts`   | `isProfileEditable` / `assertProfileEditable` 共通判定                     |
| `service-auth.ts` | `authorizeEditableBreederProfile()` — 認証 + status 検証                   |
| `loaders.ts`      | `loadBreederProfilePageContext()` — `requireBreeder()` + 非編集時 redirect |
| `layout.tsx`      | 全 Step 共通ガード（`/breeder/dashboard` へ redirect）                     |
| `service.ts`      | 全 save / upload Action にガード適用                                       |

## status 別編集可否

| status                  | 編集 |
| ----------------------- | ---- |
| `draft`                 | ✅   |
| `resubmission_required` | ✅   |
| `submitted`             | ❌   |
| `under_review`          | ❌   |
| `approved`              | ❌   |
| `rejected`              | ❌   |

---

## requireBreeder 対応

- `loadBreederProfilePageContext()` で `requireBreeder()` 使用
- Step loader（license / introduction / verification）も `requireBreeder()` に統一
- Server Action は `getCurrentBreeder()` + `authorizeEditableBreederProfile()`

---

## loader ガード

`loadBreederProfilePageContext()`:

1. `requireBreeder()`
2. `getBreederProfileContextByUserId()`
3. `isProfileEditable()` が false → `redirect("/breeder/dashboard")`

`profile/layout.tsx` で全 Step に適用。

---

## Server Action ガード

`authorizeEditableBreederProfile()` を以下の前に実行:

- `saveBasicProfile`
- `saveLocationProfile`
- `saveLicenseProfile`
- `saveIntroductionProfile`
- `uploadBreederDocument`

拒否時メッセージ: 「現在の申請状態ではプロフィールを変更できません。」

---

## upload ガード

`uploadBreederDocument` も `authorizeEditableBreederProfile()` 経由。Storage RLS 変更なし。

---

## completeBreederProfile への影響

- **`review_status === "draft"` のみ** 提出許可（既存維持）
- `resubmission_required` では `completeBreederProfile` を通さない
- 再提出 Action は **未実装**（BR-09-3）

---

## セキュリティ

- breeder 本人のみ（`getCurrentBreeder` / `requireBreeder`）
- submitted 等の直接 Action 呼び出しも拒否
- Service Role 不使用
- 内部 DB エラーは `formatProfileSaveError` で汎用化
