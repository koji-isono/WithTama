## 共通 repository

`getLatestReturnedCommentForBreeder(breederId)`:

```typescript
.eq("breeder_id", breederId)
.eq("action", "returned")
.order("created_at", { ascending: false })
.limit(1)
```

`loadLatestReturnedCommentForBreederSafely(breederId)` — エラー時 null、comment 非ログ出力。

## BR-09 Page Context 変更

`resubmission_required` のみ:

```typescript
resubmissionNotice: {
  comment: string | null;
}
```

## 表示条件・場所

| 条件                              | 表示                |
| --------------------------------- | ------------------- |
| `resubmission_required`           | ✅                  |
| その他 editable status（`draft`） | ❌                  |

## 表示文言

- 見出し: 申請内容に修正が必要です
- ラベル: 管理者からの差戻し理由
- 本文: latest returned comment（`whitespace-pre-wrap`）
- 説明: 内容を修正し、再提出してください。
