## 再提出フロー

1. 各 Step で保存（既存 save Action）
2. Step 5 で書類確認
3. `resubmission_required` 時「再提出する」
4. `resubmitBreederProfile()`:
   - `getCurrentBreeder()`
   - `getVerificationProfile()`
   - `validateProfileCompletion()`（初回提出と同一ロジック）
   - `review_status === "resubmission_required"` 確認
   - `resubmitBreederApplication()` RPC
5. 成功 → `/breeder/dashboard` へ redirect

## error handling

| ケース              | ユーザー向け文言                                                 |
| ------------------- | ---------------------------------------------------------------- |
| 必須不足            | プロフィールの必須項目が不足しています…（既存）                  |
| 不正 status         | 現在の審査状態では再提出できません。                             |
| RPC / DB 内部エラー | 再提出できませんでした。内容を確認して、もう一度お試しください。 |
| 未ログイン          | ログインが必要です。                                             |

`formatResubmitError()` で PostgreSQL code / hint / details を非露出。
