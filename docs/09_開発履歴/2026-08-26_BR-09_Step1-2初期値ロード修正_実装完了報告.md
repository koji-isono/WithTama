# BR-09 Step 1 / 2 初期値ロード修正 実装完了報告

## 目的

実ブラウザ E2E で発見した「Step 1 / Step 2 保存済み初期値未ロード」を修正し、保存済みプロフィールがフォームに表示されるようにする。

正本: [[docs/09_開発履歴/2026-08-26_BR-09_Step1-2初期値未ロード_調査報告]]

---

## 原因

Step 1（基本情報）・Step 2（所在地）に保存済みプロフィールを取得する loader がなく、フォームが常に空の `INITIAL_*` 定数で初期化されていた。

- DB データは消失していない（表示されていないだけ）
- 差戻し処理・BR-09-1 編集ガードが原因ではない
- Step 3 / 4 は既に loader + `initialInput` パターンが実装済みだった

---

## 修正概要

Step 3 / 4 と同じ構造に揃えた:

```
DB 保存値 → repository getter → loader → page Server Component → initialInput → form 初期値
```

| 項目       | 内容                                                          |
| ---------- | ------------------------------------------------------------- |
| Repository | `getBasicProfileByUserId` / `getLocationProfileByUserId` 追加 |
| Loader     | `loadBasicProfile` / `loadLocationProfile` 追加               |
| Page       | async SC + loader + `initialInput` props                      |
| Form       | `initialInput` props + `useState(initialInput)`               |
| Mapper     | `profile-input-mappers.ts`（row → input 変換）                |

---

## Repository

`src/features/breeder-profile/repository.ts`:

| 関数                         | SELECT 列                                                                      |
| ---------------------------- | ------------------------------------------------------------------------------ |
| `getBasicProfileByUserId`    | `business_name`, `representative_name`, `phone`, `public_email`, `website_url` |
| `getLocationProfileByUserId` | `postal_code`, `prefecture`, `city`, `address_line`                            |

- `user_id` で breeder 本人のみスコープ
- Server Client（RLS）のみ — Service Role 不使用
- `SELECT *` 不使用

---

## Loader

`src/features/breeder-profile/loaders.ts`:

```typescript
export async function loadBasicProfile(): Promise<BasicProfileInput> {
  const user = await requireBreeder();
  const row = await getBasicProfileByUserId(user.id);
  return mapBasicProfileRowOrEmpty(row);
}

export async function loadLocationProfile(): Promise<LocationProfileInput> {
  const user = await requireBreeder();
  const row = await getLocationProfileByUserId(user.id);
  return mapLocationProfileRowOrEmpty(row);
}
```

- `requireBreeder` パターン再利用
- `review_status` による分岐なし（編集可否は layout / Action ガードに委譲）

## initialInput

`BasicInfoStepForm` / `LocationStepForm`:

- `initialInput?: BasicProfileInput | LocationProfileInput` props 追加
- デフォルト値: 既存 `INITIAL_*` 定数（後方互換）
- `useState(initialInput)` で保存済み値を初期表示

---

## 空データ時

`mapBasicProfileRowOrEmpty` / `mapLocationProfileRowOrEmpty`:

- row が `null` の場合 → 既存 `INITIAL_*` を返却
- 新規プロフィール（DB 値なし）は従来どおり空フォーム
