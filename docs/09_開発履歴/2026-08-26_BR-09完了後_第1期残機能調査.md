### 推薦: **Stripe ブリーダー月額課金連携（Checkout + Webhook + membership_status 連携）**

| #   | 観点                | 理由                                                                                                                                                   |
| --- | ------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------ |
| 1   | 第1期リリース重要度 | 公開 View が `membership_status=active` を必須とし（Migration 実装済み）、**承認済みブリーダーの犬猫が一般公開されない**。本番リリースのボトルネック。 |
| 2   | 業務フロー依存      | フロー F（承認 → 課金 → 掲載）が唯一 **未完成** の主軸。A〜E は E2E 済み。                                                                             |
| 3   | 実装済み状況        | DB 列・Decision No.43/45/130 済み。Checkout UI / Webhook / `src/lib/stripe/` のみ未。                                                                  |
| 4   | 実装リスク          | **中〜大**（外部サービス、Webhook 冪等性、テスト環境）。ただし設計判断の大半は Decision 済み。                                                         |
| 5   | 3〜4 か月観点       | 機能実装の山は越えた。**収益化・公開条件を満たす最後のゲート**として最優先が合理的。                                                                   |
