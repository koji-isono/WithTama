## 1. 問題

ブリーダー共通ヘッダー右上に **「田中 ブリーダー」** が常時表示され、ログインユーザーに関係なく固定値だった。

---

## 2. 原因

`src/components/layout/breeder-header.tsx` に `const BREEDER_NAME = "田中 ブリーダー"` がハードコードされていた。BR-06 実装時のプレースホルダーで、実名表示は残課題として未着手だった。

---

## 3. 修正内容

| 変更             | 内容                                                                            |
| ---------------- | ------------------------------------------------------------------------------- |
| formatter 共通化 | `formatBreederDisplayName` を `src/lib/breeder/format.ts` へ移動                |
| admin            | `src/features/admin/format.ts` から re-export（二重実装なし）                   |
| loader 追加      | `loadBreederHeaderDisplayName()` — `src/features/breeder-profile/loaders.ts`    |

---

## 4. 表示名優先順位

| 優先 | 列                                            | 例               |
| ---- | --------------------------------------------- | ---------------- |
| 1    | `breeders.business_name`（trim 後非空）       | `WithTama犬舎`   |
| 2    | `breeders.representative_name`（trim 後非空） | 代表者氏名       |
| 3    | 両方 NULL/空                                  | `（名称未設定）` |

**「〇〇 ブリーダー」形式への自動付加は行わない。**

---

## 5. Auth → breeders 取得経路

```
Supabase Auth session
  └─ requireBreeder() → user.id
       └─ getBasicProfileByUserId(user.id)
            └─ .eq("user_id", userId)  （RLS: breeders_select_own）
                 └─ business_name / representative_name
                      └─ formatBreederDisplayName()
                           └─ BreederHeader displayName prop
```

- クライアントから `breeder_id` / `user_id` を指定しない
- `service_role` 不使用

## 7. Client へ渡す情報

**`displayName: string`（表示用 1 文字列）のみ。**

住所・電話・Stripe ID・内部 breeder UUID 等は Client へ渡さない。

---

## 8. セキュリティ

| 要件                      | 対応                            |
| ------------------------- | ------------------------------- |
| ログイン `user.id` を正本 | `requireBreeder()`              |
| 他 breeder を取得しない   | RLS + `.eq("user_id", user.id)` |
| `service_role` 不使用     | server session client のみ      |
| RLS 迂回なし              | 既存 `breeders_select_own`      |
| 最小限の Client 露出      | `displayName` のみ              |
