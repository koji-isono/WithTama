## 1. ログアウト実装

### 方式

```
LogoutButton onClick
  └─ signOut()  … src/lib/supabase/sign-out.ts
       └─ createClient()（@/lib/supabase/client / @supabase/ssr）
            └─ supabase.auth.signOut()  … cookie / session 無効化
  └─ router.push("/login")
  └─ router.refresh()
```

| 項目                 | 内容                                                                              |
| -------------------- | --------------------------------------------------------------------------------- |
| signOut 呼び出し場所 | `LogoutButton` → `signOut()`                                                      |
| redirect 先          | `/login`                                                                          |
| session 無効化       | Supabase Auth browser client の `signOut()`（localStorage のみ削除は **不使用**） |
| service_role         | **不使用**                                                                        |
| 失敗時               | 汎用メッセージ表示。`/login` へ遷移 **しない**                                    |
| 二重クリック防止     | `loading` state + `disabled={loading}` + early return                             |

### 新規ファイル

| ファイル                                | 役割                                                 |
| --------------------------------------- | ---------------------------------------------------- |
| `src/lib/supabase/sign-out.ts`          | `sign-in.ts` と対称の共通 signOut                    |
| `src/components/auth/logout-button.tsx` | 将来 buyer / admin でも再利用可能な Client Component |

### 変更ファイル

| ファイル                                   | 変更                           |
