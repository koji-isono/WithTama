- `periodEndLabel` の算出を presentation 生成**より前**に移動

## cancel_at_period_end=true 時の表示

```
現在の状態
解約予定

{日付}に利用終了予定です。
解約予定日までは引き続きご利用いただけます。

利用終了予定日
{日付}

［支払い方法を確認・変更］
```

日付は DB の `subscription_current_period_end` から `formatBillingPeriodEnd()` で生成。
