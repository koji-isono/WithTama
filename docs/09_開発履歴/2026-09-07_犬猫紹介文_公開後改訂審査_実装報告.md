## 5. Trigger

`enforce_pets_description_update`（BEFORE UPDATE）:

- `published` 時の `description` 直接変更 → session flag なしで拒否
- `pending_description` / `description_review_status` → RPC session flag 必須
- 既存 `enforce_pets_status_transition` と競合なし（status 不変 UPDATE は通過）

---

## 6. RPC

| RPC                                   | 主体    | 用途                            |
| ------------------------------------- | ------- | ------------------------------- |
| `save_pet_description_revision_draft` | breeder | 改訂案保存 → `draft`            |
| `submit_pet_description_revision`     | breeder | 改訂申請 → `under_review` + log |
| `approve_pet_description_revision`    | admin   | 原子的 `description` 切替       |
| `return_pet_description_revision`     | admin   | `returned` + pending 保持 + log |
| `submit_pet_for_review`（拡張）       | breeder | 初回 description 20〜2000 必須  |

---

## 7. RLS

既存 `pets_update_breeder_own` は維持。DB 迂回防止は **trigger + RPC** で担保。`pet_review_logs` INSERT ポリシーを `description_*` action 対応に拡張。

---

## 8. pet_review_logs

追加 action: `description_submitted` / `description_approved` / `description_returned`（`description_returned` は comment 必須）。

---

## 9. BR-08

`PetDraftFormFields` に **紹介文** textarea 追加。description 未入力でも draft 保存可。

---

## 10. BR-11

| 状態           | UI                                                                        |
| -------------- | ------------------------------------------------------------------------- |
| `draft`        | 紹介文編集可                                                              |
| `under_review` | 紹介文 read-only                                                          |

---

## 11. AD-10

同一一覧に **新規掲載 / 紹介文変更** Badge。取得: `status=under_review` OR (`published` AND `description_review_status=under_review`)。

---

## 12. AD-11

`reviewType` 分岐。紹介文変更時は **現在公開中 vs 変更後** 比較セクション + 専用 approve/return RPC。

---

## 13. Public View

**変更なし**。`published_pet_detail_public` は `description` のみ。DTO も pending 系非含有。

---

## 14. Validation

| タイミング   | ルール                             |
| ------------ | ---------------------------------- |
| 保存         | 任意、max 2000、空白→NULL          |
| 初回公開申請 | trim 後 20〜2000 必須              |
| 改訂申請     | trim 後 20〜2000、現行文と同一不可 |

- published `description` 直接 UPDATE: trigger 拒否（CASE S 想定）
