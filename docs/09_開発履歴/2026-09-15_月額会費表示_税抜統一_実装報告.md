# 月額会費表示 税抜統一 実装報告

| 項目   | 内容                                                      |
| ------ | --------------------------------------------------------- |
| 作業日 | 2026-09-15                                                |
| 種別   | **UI 表示修正**（Stripe / DB / Webhook 変更なし）         |
| 背景   | Stripe 本番設定は 5,000円（税抜）+ 10% 外税 = 5,500円請求 |

---

## 1. 目的

ブリーダー月額会費画面および関連表示で **「月額 5,000円（税込）」** となっていた箇所を、実装・Stripe 設定に合わせ **「月額 5,000円（税抜）」** に統一する。

| 項目          | 内容                                           |
| ------------- | ---------------------------------------------- |
| Stripe Price  | 5,000円（税抜）— env `STRIPE_BREEDER_PRICE_ID` |
| 消費税        | 10% 外税 — env `STRIPE_BREEDER_TAX_RATE_ID`    |
| Checkout 請求 | 5,500円（税込）— Stripe 側で計算               |
| 変更対象      | **表示ラベルのみ**                             |
