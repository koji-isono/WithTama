## 0. 冒頭説明（担当者向け — 約 1 分）

**WithTama**（https://withtama.jp）は、**第一種動物取扱業の登録を受けたブリーダー** と、犬猫を家族として迎えたい **購入希望者** をつなぐ **会員制 Web サービス** です。運営会社は **株式会社システムサイエンス** です。

WithTama 運営会社は、次のとおり **犬猫の取扱い・売買には関与しない** 設計です。

| 項目                 | WithTama 運営 |
| -------------------- | ------------- |
| 犬猫を所有する       | **しない**    |
| 犬猫を仕入れる       | **しない**    |
| 犬猫を飼養・保管する | **しない**    |
| 犬猫を展示する       | **しない**    |
| 犬猫の売買契約当事者 | **ならない**  |
| 犬猫代金を受領する   | **しない**    |
| 成約手数料を受領する | **しない**    |

**犬猫の売買契約は、ブリーダーと購入者の間** で行います。WithTama が受領するのは、ブリーダーからの **月額 Web サービス利用料 5,000 円（税抜）** のみです（Stripe で月額会費を徴収。犬猫代金のオンライン決済は **提供しません**）。

Web サイトでは犬猫情報を閲覧し、**問い合わせ・見学希望を送るところまで** を提供します。売買を Web だけで完結させず、次の流れを想定しています。

```
問い合わせ → 見学希望 → ブリーダー事業所で現物確認・対面説明 → その後に売買（サイト外）
```

## 4. 質問④ 現物確認・対面説明

WithTama では、次の流れを想定しています。

```
Web 問い合わせ
    ↓
見学希望
    ↓
ブリーダー事業所訪問
    ↓
犬猫の現物確認
    ↓
ブリーダーによる対面説明
    ↓
売買契約（サイト外 — WithTama は非関与）
```

**質問**

この流れについて、**動物愛護管理法上の販売時の現物確認・対面説明** の考え方として問題ないでしょうか。

あわせて以下を確認したいです。

| #   | 確認事項                                                                                                  |
| --- | --------------------------------------------------------------------------------------------------------- |
| 1   | 現物確認は **必ずブリーダーの事業所** で行う必要があるか                                                  |
| 2   | **対面説明を行うタイミング**                                                                              |
| 3   | **売買契約を締結できるタイミング**                                                                        |
| 4   | WithTama 上で **現物確認実施記録** を残すことに問題ないか                                                 |
| 5   | WithTama 上で **対面説明実施記録** を残すことに問題ないか                                                 |
| 6   | 現在 WithTama が想定している **18 項目**（環境省「対面説明が必要な18項目」）の確認記録で **不足がないか** |
| 7   | **記録として保存すべき項目**                                                                              |
| 8   | **法令上必要な保存期間**                                                                                  |

**WithTama 第1期のシステム記録（参考 — 実装済）**

| 項目         | 内容                                                                 |
| ------------ | -------------------------------------------------------------------- |
| 画面         | BR-15 見学詳細（ブリーダー向け `/breeder/visits/[visitId]`）         |
| 現物確認     | checkbox `animal_confirmed`（**実施有無のみ**）                      |
| 対面説明     | checkbox `explanation_completed`（**実施有無のみ**）                 |
| 未実装       | 実施日時・担当者・電子署名、18 項目の **個別記録 UI**                |
| サイト内契約 | **なし**（成約結果は「サイト外で別途行われた結果の記録」として扱う） |

**参考:** 環境省「[対面説明が必要な18項目](https://www.env.go.jp/nature/dobutsu/aigo/pickup/list_18.html)」（品種名、飼養方法、病歴・ワクチン等 — 全 18 項目は同ページ参照）
